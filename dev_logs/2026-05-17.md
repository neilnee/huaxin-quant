## API 踩坑记录

| 坑 | 现象 | 解决 |
|----|------|------|
| 行业列不返回 | 查询不含行业关键词时 `INDUSTRY` 列缺失 | 加「按行业分类」触发词 |
| 条件口径漂移 | 去所有年份前缀后，归母净利润从年度 3186 只跌到单季度 1786 只 | 仅去毛利率前缀 |
| 数据字段缺失 | 部分标的缺少特定报告期字段（如 2025 年报毛利率） | 关键字段不用年份锁定 |
| API 200 条上限 | 无 R&D 条件时 205 只，仅返回 200 | 记入策略文档，后续超过需分批 |
| mx-data 403 | 查数接口返回 403 | 改用 xuangu 单独查验证 |
| mx-data 单次实体上限 | 批量查 60 只仅识别前 5 个 | 单体查询 |
| 概念/行业接口不存在 | API 不提供板块枚举端点 | 通过 WebFetch 公开接口获取 |
