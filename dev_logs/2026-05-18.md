## 两个关键bug发现

### LATEST 陷阱（OCF/NP 虚高）

昨天 build_pool.py 用 `find_key("NETOPERATECASHFLOW","LATEST")` 匹配字段，实际命中了 `#LATEST#` 版本（疑似2026Q1单季度数据），导致9只标的OCF/NP虚高误入池。

典型案例：金力永磁(300748) — 昨天 OCF/NP=1.83，今天用2025年报数据重算 = 0.50。差异来自分母（单季度NP小 → 比值大；全年NP大 → 比值小）。

**修复**: 字段匹配强制锁定 `2025-12-31` 报告期，禁用 `#LATEST#`。

### 行业字段选错（排除漏网）

`INDUSTRY`（东财二级短名）返回 `环境治理`，不含"环保"关键词，导致8只环保、农林牧渔、建筑装饰类标的未被排除。

**修复**: 优先用 `SW_INDUSTRY`（三级全路径如 `环保-环境治理-固废治理`），排除关键词能命中一级分类。

## 模型二开发历程

### API 数据源验证

用 mx-data 拉润泽科技（300442）近 60 天日线，关键发现：
- `rawTable` 纯数字无中文单位（成交量=股数、价格=元、换手率=%），可直接 float 解析
- `table` 带中文单位（`亿股`/`万股`/`元`/`%`），不适合批量处理
- 停牌日成交量/换手率为 `-`，需过滤
- 每次返回 2 张表（Table 0 实时 + Table 1 历史），只取 Table 1
- 单次查询仅限一只股票，167 只需要 167 次调用（500 次/天配额下占 33%）

### 量价筛选规则设计

三类形态覆盖 A 股主流量价模式：

| 类别 | 形态 | 核心条件 |
|------|------|----------|
| A 缩量回调 | 主力建仓后洗盘 | 近20日有放量 + 当前缩量<0.85 + 回踩MA20/MA60 + 趋势未坏 |
| B 放量突破 | 底部盘整后起涨 | 均线粘合≥7/10天 + 近3日放量 + 站上MA60 + 涨幅<15% |
| C 趋势回踩 | 上升趋势中休整 | 多头排列 + 缩量<0.85 + 回踩MA20 + 未破前低 + 涨幅<15% |

### 阈值迭代

| 版本 | 缩量阈值 | 通过数 | 通过率 |
|------|---------|--------|--------|
| 初版 | 0.80 | 9 | 5.4% |
| 最终 | **0.85** | **19** | **11.4%** |

0.80 → 0.85 捕捉"刚开始缩量"的早期阶段，新增宁德时代、新宙邦、天赐材料等优质标的，A类从 5→11 只。B类始终 0 只——当前市场缺乏均线粘合+放量突破的标的，不是规则问题。

### 限流器（RateLimiter）

- 基础间隔 0.8s + 随机抖动 0.4s
- 连续失败指数退避（2s→4s→8s，上限 30s）
- 每 50 次额外歇 3s（长跑减压）
- FATAL 熔断（code=113/114 全局停止）
