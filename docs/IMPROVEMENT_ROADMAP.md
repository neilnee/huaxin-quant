# 工程与策略改进路线图

审查日期：2026-09-08。本文记录实现缺口、改进顺序和验收要求；所有“待实现”内容均不是现行策略。任务状态在 [TODO](../TODO.md) 维护，现状架构见 [DESIGN](../DESIGN.md)。

## 审查依据与限制

本轮检查了核心指令卡、配置、主要数据与执行代码、现有测试及本地运行产物。306 项测试通过，行情库与策略库 SQLite quick_check 通过。未重跑外部 API、完整历史策略或实际交易；没有把测试通过解释为策略有效，也没有改变策略阈值。

当前优点包括共享 SQLite、公司行为审计、原子发布、运行锁、确定性规则、估值证据门禁和运行包恢复。后续保留这些基础，按下表逐项验收。

## P1：验证策略，再连接账户

| ID | 待实现方案 | 验收标准 |
|---|---|---|
| R6 | 冻结候选策略版本；比较全部模型二信号、A/B 信号、叠加环境信号；加入基准、超额收益及样本外跟踪 | 分类型/等级/版本报告样本、收益、超额、保留率与赢家遗漏；按股票、结构及日期处理相关性；阈值只在后续版本调整 |
| R7 | 明确仓位百分比分母；抽离 Dashboard 内仓位计算，加入现金、总敞口、单票/行业上限与失效距离 | 每条建议可追溯账户快照和风险预算；多信号并发不超预算；账户缺失不得伪装通过风控 |
| R8 | 独立持仓监控覆盖全部真实持仓；补齐账本测试 | FIFO、超卖、费用、分红、拆分、晚补重建可核对；移出候选池仍继续监控；不自动改交易流水 |
| R9 | 区分核心池财务核验通过与关键字段缺失保留 | 标签、来源与原始字段对账；缺失不误报为全项核验；是否增加硬门槛单独研究 |
| R10 | 为机构共识补充覆盖率、有效样本、预测修订和实际业绩验证 | 逐机构利润/目标估值可追溯，报告日期和样本不足显式展示；不以当前隐含 PE 补目标估值 |
| R11 | 完善运行健康分层、配置契约、依赖环境与备份恢复 | 核心失败和辅助降级分开；非法类型/范围拒绝；不可重取快照与账本能在隔离目录恢复并对账 |

目前回测是事件总回报研究。真实执行模拟仍需另行定义成交时点、费用/滑点、不能成交情形、退出和组合再平衡；不能用信号成立日收盘参考价直接声称可实现账户收益。

## P2：维护成本与旁路扩展

- 按相关改动逐步抽离 Quant 和估值编排纯函数，保留现有 CLI 与输出契约；不以文件行数为理由整体重写。
- 宏观先完成多日稳定性和事件历史回放，再发布独立 Context；资金/宏观是否影响买点或风险预算，以增量验证决定。
- 估值队列与 ETF 策略属于后续设计，不是现有每日固定步骤。先完成 R1–R8，再明确消费契约。

3. 完成相关回归与差异说明后更新 TODO；代码和规则同批提交。
4. 文档修订只校正当前描述时，不递增策略版本，不将计划标记为实现。
