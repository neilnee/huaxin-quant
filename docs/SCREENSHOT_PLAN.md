## 统一拍摄规范

- 浏览器视口：`1600 × 1000`，设备缩放 100%，桌面布局。
- 输出格式：PNG，RGB；Hero 可裁为约 16:9，其余保持统一宽度。
- 主题：使用当前 Dashboard 深色主题，不额外套设备模型或营销边框。
- 日期：页面日期必须清晰可见；不同数据日期不得通过裁切隐藏。
- 构图：保留模块标题、状态标签和关键表头，避免截到半行或无上下文数字。
- 交互状态：选择最能说明能力的板块或股票，并保持左侧选中项与右侧详情一致。
- 文件体积：单张优先控制在 1.5 MB 内；只做无损或高质量压缩，不降低文字可读性。
- 命名：全部使用小写英文和数据日，不覆盖旧文件，确认后再删除废弃图片。

## 脱敏清单

拍摄前逐项检查：

- 不出现 `.env`、API Key、请求 Header 或服务端凭据。
- 不出现东方财富账户、自选分组、用户昵称或同步日志。
- 不出现真实持仓数量、成本、账户资产或盈亏。
- 不出现本机绝对路径、云盘目录或用户名。
- 不出现未公开研报原文、付费材料正文或受限链接。
- 个股名称与证券代码统一替换为圆点遮罩；板块名、模型结构、资金日期和评价字段可以保留。
- 估值页额外隐藏公司专属摘要、现价、目标价和机构取值依据。
- 股票行情与模型输出只展示无法关联具体标的的结构信息，图注保留“研究与复盘，不构成投资建议”。
