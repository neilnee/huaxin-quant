- **版本**: v1.6

- **核心哲学**: 只看"已兑现"的资产历史质量，先让数据说话，再用行业标签做减法
- **配套脚本**: `scripts/process_pool.py` — 阶段二~五的数据处理（合并去重、自算过滤、行业排除、CSV输出）

  - v20260518: 重构执行步骤 — 市值分段替代排序轮询，行业排除改为字段匹配，详细化每步操作

---

## 总览

本任务分 **5 个阶段**，每阶段有明确的输入、输出和操作规范。

```
阶段一（mx-xuangu）→ 阶段二（自算过滤）→ 阶段三（行业排除）→ 阶段四（输出CSV）→ 阶段五（打印摘要）
```

**核心设计原则**:
- API 能算的交给 API（增速、毛利率、研发占比、ST）
- API 算不了的自己算（OCF/NP 比值、上市天数）
- 数据一次拉取，不在中间环节重复调 API
- 市值分段互斥查询，解决 200 条上限

## 阶段一：市值分段拉取初筛池

### 目标
从全市场获取满足 5 项 API 条件的股票，同时拉回全部原始字段供后续阶段使用（行业、估值、财务、上市日期等共 13 个字段）。

### 查询模板

对每个市值分段，使用 mx-xuangu Skill 查询。**替换 `{市值范围}` 部分**：

```
营收同比增长率大于15% 净利润同比增长率大于20% 毛利率大于15% 研发费用占营收比例(2025年)大于2.5% 排除ST股 {市值范围} 查询所属行业 上市日期 总市值 市盈率 市净率 ROE 营业收入(2025年年报) 每股收益(2025年年报) 经营活动产生的现金流量净额(2025年年报) 归属母公司股东的净利润(2025年年报) 资产负债率 A股
```

**字段说明**:

| 查询中的字段 | 用途 | 阶段 |
|-------------|------|------|
| 营收同比增长率 > 15% | API 侧过滤 | — |
| 净利润同比增长率 > 20% | API 侧过滤 | — |
| 毛利率 > 15% | API 侧过滤（**不加年份**，原因见踩坑#3） | — |
| 研发费用占营收比例(2025年) > 2.5% | API 侧过滤 | — |
| 排除ST股 | API 侧过滤 | — |
| 查询所属行业 | 行业排除 | 三 |
| 上市日期 | 计算上市天数 | 二 |
| 总市值 | 输出字段 | 四 |
| 市盈率 | 输出字段 | 四 |
| 市净率 | 输出字段 | 四 |
| ROE | 输出字段 | 四 |
| 营业收入(2025年报) | 输出字段 | 四 |
| 每股收益(2025年报) | 输出字段 | 四 |
| 经营活动现金流(2025年报) | 计算 OCF/NP 比值 + 输出 | 二/四 |
| 归母净利润(2025年报) | 计算 NP>5000万 + OCF/NP 比值 + 输出 | 二/四 |
| 资产负债率 | 判断 < 70% + 输出 | 二/四 |

### 市值分段（5段，互斥）

```
段1: 总市值小于50亿
段2: 总市值大于50亿 总市值小于100亿
段3: 总市值大于100亿 总市值小于200亿
段4: 总市值大于200亿 总市值小于500亿
段5: 总市值大于500亿
```

**段边界策略**: 50亿、100亿、200亿、500亿。若某段仍然 ≥200 条（total 字段显示），对该段再按市盈率正序/倒序拆成两次查询（追加 `按市盈率从小到大` / `按市盈率从大到小`）。

### 执行步骤

1. 对每个分段拼完整查询字符串，调用 mx-xuangu Skill
2. 检查返回数据中的 `total` 字段：
   - `total < 200`：本段全覆盖，提取 `dataList` 全部记录
   - `total >= 200`：本段截断，启动子分段（见上）
3. 以 `SECURITY_CODE`（补零到 6 位）为 key，合并所有分段结果，去重
4. 打印每段日志：段号、返回条数、total、累计去重数

### 预期输出
合并去重后的股票列表（dict/list），每条包含：SECURITY_CODE, SECURITY_SHORT_NAME, 行业字段, 上市日期, 经营现金流, 归母净利润, 资产负债率, 及各增速/比率字段。

## 阶段二：自算过滤

### 目标
对阶段一结果，计算 API 无法处理的 4 个硬性门槛。

### 2.1 字段匹配规则

**API 返回的字段 key 是动态生成的**（如 `010000_RPT_..._PARENTNETPROFIT{2025-12-31}`），必须用**模糊匹配**，不能用精确 key。

**⚠️ 核心原则：年度数据必须锁定报告期，禁止用 `#LATEST#`。**

同一字段可能存在多个版本的 key（如 `{2025-12-31}` 年报 和 `#LATEST#` 最新期），`#LATEST#` 可能返回的是单季度数据（如 2026Q1）而非年度数据，导致 OCF/NP 比值虚高。**匹配时必须同时命中报告期标识 `2025-12-31`**，仅命中 `LATEST` 的 key 跳过不用。

匹配规则如下（按优先级排列，命中高优先级即停止）：

| 目标字段 | 匹配方式（按优先级） |
|---------|---------------------|
| 归母净利润(2025年报) | ① key 含 `PARENTNETPROFIT` **且** 含 `2025-12-31` |
| 经营现金流(2025年报) | ① key 含 `NETOPERATECASHFLOW` **且** 含 `2025-12-31` |
| 营业收入(2025年报) | ① key 含 `OPERATEREVE` **且** 含 `2025-12-31` |
| 每股收益(2025年报) | ① key 含 `EPSJB` **且** 含 `2025-12-31`；② key 含 `BASICEPS` **且** 含 `2025-12-31` |
| 资产负债率 | ① key 含 `ZCFZL`；② key 含 `资产负债` 或 `DEBT_ASSET` |
| 上市日期 | ① key 含 `LISTING_DATE` |
| 所属行业 | ① key 含 `SW_INDUSTRY`（三级全路径，排除更精准）；② key 含 `INDUSTRY`（二级短名） |
| 总市值 | ① key 含 `TOAL_MARKET_VALUE`；② key 含 `总市值` |
| 市盈率 | ① key 含 `PETTM`；② key 含 `市盈率` |
| 市净率 | ① key 含 `PB<` 或 `_PB_`；② key 含 `市净率` |
| ROE | ① key 含 `ROE_WEIGHT`；② key 含 `ROE` 或 `净资产收益率` |
| 营收同比增速 | ① key 含 `营业收入最新同比增长率` |
| 净利同比增速 | ① key 含 `归属母公司股东的净利润最新同比增长率` |
| 毛利率 | ① key 含 `XSMLL` |
| 研发费用占比 | ① key 含 `RDRATIO` |

**为什么用模糊匹配**: API 返回的 key 名在同一字段上会随查询组合变化（如加/不加行业关键词时 key 不同），精确匹配会导致字段匹配失败。

### 2.2 数值解析规则

API 返回的值为字符串，带单位后缀时需解析：

```
"2.18亿"     → 218000000       （去掉"亿" × 10^8）
"5000万"     → 50000000        （去掉"万" × 10^4）
"41.40"      → 41.40           （百分比/小数直接 parse）
"2020-10-28" → Date 对象       （上市日期）
```

**管道符处理**: 值中 `|` 后的内容（如报告期标注）丢弃，只取 `|` 前部分。

### 2.3 半导体高增长判定（前置）

在进入过滤条件前，先判定该票是否适用半导体高增长豁免：

```
is_semi  = 行业字段.includes("半导体")
rev_g    = parseNum(营收同比增速)
semi_relax = is_semi && rev_g > 25
```

`semi_relax = true` 时，条件 B（OCF/NP）**豁免不做**，条件 E（毛利率）使用 **半导体放宽阈值 15%** 替代通用阈值 20%。

### 2.4 过滤条件（按顺序执行，不满足即剔除）

**条件 A — 上市时长 ≥ 1年**
```
list_date = parseDate(上市日期)
if (今天 - list_date) 天数 < 365 → 剔除
```
若上市日期字段缺失 → **保留**（宁可漏过不可误杀）。

**条件 B — 经营现金流 / 净利润 > 0.5**（semi_relax 豁免）
```
if semi_relax → 跳过本条
ocf = parseNum(经营现金流_2025年报)
np  = parseNum(归母净利润_2025年报)

if np <= 0    → 剔除（亏损企业不参与比值）
if ocf / np <= 0.5 → 剔除
if 任一字段缺失 → 保留
```

**条件 C — 归母净利润(2025年报) > 5000万元**
```
np = parseNum(归母净利润_2025年报)
if np < 50,000,000 → 剔除
if 字段缺失 → 保留
```

**条件 D — 资产负债率 < 70%**
```
debt = parseNum(资产负债率)
if debt >= 70 → 剔除
if 字段缺失 → 保留
```

**条件 E — 毛利率分档检查（阶段二自算）**
```
gm = parseNum(毛利率)

if semi_relax:
    if gm < 15 → 剔除（"毛利率<15%(半导体高增长)"）
else:
    if gm < 20 → 剔除（"毛利率<20%(非半导体)"）

if 字段缺失 → 保留
```

> 背景：阶段一 API 毛利率门槛已从 20% 降到 15%，因此阶段二补回分档检查，确保非半导体维持 20% 硬底线。

### 2.5 输出
打印各条件剔除计数，输出通过列表。

## 阶段三：行业排除

### 目标
基于阶段一已返回的行业字段，剔除不相关行业。

### 执行方式
直接遍历阶段二通过列表，检查每条记录的行业字段是否命中排除列表。**不额外调 API**。

### 排除行业关键词

以下关键词命中任一条即剔除（用 `includes` 部分匹配）：

```
银行、保险、证券、多元金融、
白酒、食品饮料、服装家纺、家用电器、旅游零售、农林牧渔、商业物业经营、
房地产开发、房地产服务、水泥、建筑装饰、
煤炭、钢铁、石油石化、航运港口、航空机场、
燃气、水务、环保
```

### 匹配规则
`行业字段字符串.includes(关键词)` — 部分匹配即可。例如行业返回 `环保-环境治理-固废治理`，包含 `环保` 即命中剔除。

**行业字段选择**: 优先使用 `SW_INDUSTRY`（东财三级全路径，如 `环保-环境治理-固废治理`），因为排除关键词（如"环保"）能直接命中三级路径中的一级分类。若使用 `INDUSTRY`（东财二级短名，如 `环境治理`），排除关键词无法命中，会导致漏网。

**不在排除列表中的行业，一律保留。**

### 输出
打印剔除的行业分布，输出最终入池股票列表。

### 股票代码写入规则（强制）

```
写入 CSV 时，代码值必须写成 ="{code}" 公式文本格式
例如: ="000001" , ="300442" , ="688676"
严禁: 000001（纯数字，Excel 会吞掉前导零）
严禁: '000001（单引号前缀）
```

### 数值解析伪代码

```python
def parse_num(v: str) -> float | None:
    """'17.04亿' → 1704000000.0, '5000万' → 50000000.0"""
    s = v.split("|")[0].strip().replace(",", "")
    if "亿" in s: return float(s.replace("亿", "")) * 1e8
    if "万" in s: return float(s.replace("万", "")) * 1e4
    if "元" in s: return float(s.replace("元", ""))
    return float(s)

def format_num(v: float | None) -> str:
    """1704000000.0 → '1704000000.00'"""
    if v is None: return ""
    return f"{v:.2f}"
```

## 阶段五：打印摘要

执行完成后在终端输出：

1. **各阶段计数**:
   ```
   阶段一: API 拉取 X 只（理论总数 Y，覆盖率 Z%）
   阶段二: 通过 A 只
     - OCF/NP不达标: B 只
     - 负债率过高: C 只
   ```

4. **截断警告**: 若任一分段触发子分段且仍覆盖不全，打印 `⚠️ 截断警告：段X 实际返回 Y，理论总数 Z`

## 附录：历史踩坑记录

| # | 问题 | 现象 | 正确做法 |
|---|------|------|---------|
| 1 | 行业列缺失 | 查询字符串不含行业触发词时，API 不返回行业字段 | 查询中必须写「查询所属行业」或「按行业分类」 |
| 2 | 数据口径漂移 | 去掉年份前缀后，归母净利润从年报值跌到单季度值，候选池大幅缩水 | 原始字段请求保留年份后缀（如 `2025年年报`） |
| 3 | 毛利率字段缺失 | 部分标的（如润泽科技 300442）缺失 `2025年销售毛利率` 字段，被 API 条件误排除 | 毛利率过滤不加年份前缀，让 API 自动取最新可用值 |
| 4 | API 200 条截断 | 全市场初筛 total=549，单次仅返回 200 | 市值分段互斥查询 |
| 5 | 字段 key 动态变化 | 同一数据字段在不同查询组合下 key 名不同 | 用 includes/contains 模糊匹配，禁用精确 key |
| 6 | 白名单漏标的 | 润泽科技东财分类为"通信服务"不在预设白名单，正确标的被排除 | 全市场初筛 + 行业黑名单 |
| 7 | LATEST 陷阱 | `find_key("NETOPERATECASHFLOW","LATEST")` 匹配到 `#LATEST#` 版本（疑似 2026Q1 单季度数据），OCF/NP 比值虚高，导致 9 只标的误入池（如金力永磁 OCF/NP=1.83 实为 0.50） | 字段匹配必须同时命中 `2025-12-31` 年报报告期，跳过仅含 `LATEST` 的 key |
| 8 | 行业字段选错 | 使用 `INDUSTRY`（东财二级短名如"环境治理"）导致"环保"类 8 只标未被排除 | 优先用 `SW_INDUSTRY`（三级全路径如"环保-环境治理-固废治理"） |
