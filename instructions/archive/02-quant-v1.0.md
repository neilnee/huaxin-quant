# 模型二：量价精筛模型（自执行指令）

- **版本**: v1.0
- **日期**: 2026-05-18
- **核心目标**: 从模型一候选池中，用量价技术指标筛选出"正在被资金关注、处于起涨初期"的标的，输出精选池供模型三做深度估值。
- **核心哲学**: 只看资金行为，不看公司质地。找"主力已进场、当前在休整、尚未加速拉升"的中间蓄力阶段。模型二不产生交易信号，只做技术面初筛。
- **输入**: `pool/pool_<YYMMDD>.csv`（模型一产出）
- **输出**: `quant/quant_<YYMMDD>.csv`（精选池，供模型三使用）
- **配套脚本**: `scripts/quant_filter.py`（v1.0，与指令版本同步）
- **设计参考**: 基于模型一 v1.6 的工程风格和踩坑经验
- **核心特性**:
  - 三类量价形态筛选（A缩量回调 / B放量突破 / C趋势回踩）
  - 本地日线缓存（`cache/daily/`），同日零重复 API
  - RateLimiter 限流（抖动+退避+熔断）
  - 14 列输出含入选原因

---

## 总览

本任务分 **4 个阶段**，每阶段有明确的输入、输出和操作规范。

阶段一（拉取行情）→ 阶段二（计算指标）→ 阶段三（执行筛选）→ 阶段四（输出精选池）

**核心设计原则**:
- 数据拉取用妙想金融数据 API 直调（`mkapi2.dfcfs.com`），取 `rawTable` 避免中文单位解析
- 技术指标用 Python 本地批量计算（pandas/numpy），不逐只调 API
- 筛选规则基于均线趋势、量价配合、位置判断三个维度
- 模型二只做技术面筛选，不替代模型三的估值判断
- 日线数据本地缓存（`cache/daily/`），同一标的同一交易日只拉一次，后续分析零 API 消耗
- 脚本版本与指令版本同步，旧版本逻辑不保留

## 阶段一：拉取行情数据

### 目标
从妙想金融数据 Skill 逐只拉取模型一候选池中所有股票的近60个交易日日线数据。

### 数据源
使用 `妙想金融数据` Skill，对每只股票查询近60个交易日日线行情。

### 拉取规范

**查询参数**:
- 股票代码：从 `pool/pool_<YYMMDD>.csv` 读取
- 数据周期：近60个交易日
- 目标表格：取 `dataTableDTOList[1].rawTable`（历史日线数据，忽略 Table 0 的当日实时快照）

**需要字段**:
- 交易日期：排序、计算均线（阶段二）
- 开盘价：计算涨跌幅、形态识别（阶段二）
- 最高价：计算突破幅度（阶段二）
- 最低价：判断支撑位（阶段二）
- 收盘价：均线、突破、位置判断（阶段二/三）
- 成交量：放量/缩量、量比（阶段二/三）
- 换手率：流动性判断（阶段二/三）

**数据清洗规则**:
- 过滤停牌日：成交量/换手率为 `-` 的行直接跳过
- 日期排序：按交易日期升序排列
- 数值类型：价格、成交量、换手率均转为 float
- 价格复权：先取 1-2 只有近期除权的股票验证 API 返回价格是否连续（不复权在除权除息日会出现跳空，均线计算失真）。若确认不复权，后续版本需引入前复权处理；当前先标注此风险，筛选逻辑暂按不复权数据运行

**调用约束**:
- 采用串行执行（不引入并发），每只打印进度日志。150 只 × 约 1-2s/只 ≈ 3-5 分钟
- 每日配额 500 次，150 只候选池消耗约 30%，余量充足
- 限流策略（`RateLimiter`）：
  - 基础间隔：0.8s + 0.4s 随机抖动（避免请求节奏被服务端识别）
  - 指数退避：连续失败后 2s → 4s → 8s（上限 30s），成功后重置
  - 批次歇息：每 50 次调用额外 +3s（长跑减压）
  - FATAL 熔断：code=113（配额上限）/ code=114（Key 失效）→ 全局停止，后续标的直接跳过
- 重试策略按错误类型分类：
  - 网络超时/连接错误 → 重试 1 次，间隔含退避
  - code=112（频率限制）→ 重试 1 次，间隔含退避
  - code=113（调用次数达上限）→ FATAL，停止全部
  - code=114（API Key 失效）→ FATAL，直接退出
  - code=115（查询无结果）→ 不重试，记录后跳过
  - 单只数据为空（长期停牌）→ 不算失败，记录后跳过

### 预期输出
一个 dict，key 为股票代码，value 为 DataFrame（60行 × 7列：日期、开、高、低、收、成交量、换手率）。

### 数据完整性检查（阶段一完成立即可执行）

对每只股票的有效交易日计数（排除停牌日和 `-` 行），按以下规则分层：

| 有效交易日 | 处理方式 |
|-----------|----------|
| < 20 天 | 直接跳过，连 MA20 都无法计算，标记为"数据不足" |
| 20-59 天 | 可计算 MA20 及依赖 MA20 的指标，但 MA60 相关条件（B3 站上 MA60、C1 多头排列、距 MA60 等）不可用。仍参与后续筛选，但 B 类和 C 类中依赖 MA60 的判定自动视为不满足 |
| >= 60 天 | 正常参与全部筛选 |

在终端输出中打印数据完整性统计：
- 数据完整（>= 60 天）: X 只
- 数据不足（< 20 天）: Y 只（跳过）
- 部分完整（20-59 天）: Z 只（MA60 条件不可用）

### 日线数据缓存（阶段一的工程基础设施）

为避免同一交易日反复拉取同一标的浪费 API 配额，脚本内置本地缓存层。

**缓存目录**: `cache/daily/<code>_<YYMMDD>.pkl`
- 每只股票每天一个 pickle 文件（DataFrame 序列化），存储清洗后的日线数据（不含指标列，指标每次实时计算以适应规则变更）
- 167 只约 1.3MB，可忽略

**缓存策略**:
- 同一标的 + 同一日期：命中缓存，零 API 调用（适合反复调试筛选参数）
- 日期变更：旧缓存不命中（文件名日期对不上），自动重新拉取并更新
- 脚本版本升级：旧缓存自然过期（次日即刷新），无需手动清理

**CLI 控制**（`scripts/quant_filter.py`）:
```bash
python3 scripts/quant_filter.py                     # 默认：走缓存
python3 scripts/quant_filter.py --test              # 测试模式（内建 19 只标的）
python3 scripts/quant_filter.py --test --no-cache   # 跳过缓存，强制 API 拉取
python3 scripts/quant_filter.py --refresh           # 清除今日全部缓存后重新拉全量
python3 scripts/quant_filter.py --pool pool/xxx.csv # 指定池文件
python3 scripts/quant_filter.py --quant quant/xxx.csv # 指定输出路径
```

**工程约束**:
- 缓存 DataFrames 不含指标列（指标在阶段二实时计算），确保筛选规则迭代时不会被旧缓存污染
- 缓存损坏自动删除并重新拉取
- 脚本版本号与指令版本号同步（当前均为 v1.2），规则变更时两者同步更新

## 阶段二：计算技术指标

### 目标
对每只股票的日线数据，批量计算各项技术指标，作为阶段三筛选的输入。

### 指标清单

**2.1 均线系统**
- MA20：近20个交易日收盘价的算术平均，判断中期趋势、回踩支撑
- MA60：近60个交易日收盘价的算术平均，判断长期趋势、突破信号

**2.2 成交量指标**
- 量比：当日成交量 ÷ 前5个交易日均量，判断当日是否放量
- 近5日均量：近5个交易日成交量的算术平均，判断短期量能
- 近20日均量：近20个交易日成交量的算术平均，判断中期量能
- 缩量程度：近5日均量 ÷ 近20日均量，判断是否缩量回调
- 近20日均成交额：近20个交易日（成交量 × 收盘价）的算术平均，判断流动性（避免股数门槛对高价/低价股的分化）

**2.3 价格位置指标**
- 收盘价相对MA20位置：(收盘价 - MA20) ÷ MA20 × 100%，判断是否在均线附近
- 收盘价相对MA60位置：(收盘价 - MA60) ÷ MA60 × 100%，判断突破幅度
- 近5日涨幅：(最近收盘价 - 5日前收盘价) ÷ 5日前收盘价 × 100%，判断是否已加速
- 近20日最高价：近20个交易日最高价的最高值，判断是否接近前高
- 距60日高点幅度：(收盘价 - 60日最高价) ÷ 60日最高价 × 100%，判断是否处于高位

**2.4 均线关系指标**
- MA20与MA60差距：(MA20 - MA60) ÷ MA60 × 100%，判断多头/空头/粘合

### 计算方式
使用 Python pandas 对所有股票批量计算，不逐只调 API。伪代码框架：

import pandas as pd
import numpy as np

def calc_indicators(df):
    # df: 单只股票的日线数据，按日期升序
    df['MA20'] = df['close'].rolling(20).mean()
    df['MA60'] = df['close'].rolling(60).mean()
    df['vol_ma5'] = df['volume'].rolling(5).mean()
    df['vol_ma20'] = df['volume'].rolling(20).mean()
    df['amount'] = df['volume'] * df['close']  # 日成交额
    df['amount_ma20'] = df['amount'].rolling(20).mean()  # 近20日均成交额
    df['量比'] = df['volume'] / df['vol_ma5'].shift(1)
    df['缩量程度'] = df['vol_ma5'] / df['vol_ma20']
    df['距MA20'] = (df['close'] - df['MA20']) / df['MA20'] * 100
    df['距MA60'] = (df['close'] - df['MA60']) / df['MA60'] * 100
    df['近5日涨幅'] = df['close'].pct_change(5) * 100
    df['MA20_MA60差'] = (df['MA20'] - df['MA60']) / df['MA60'] * 100
    return df

### 预期输出
每只股票的 DataFrame 新增上述指标列，取最新交易日的数据作为阶段三的判断依据。

## 阶段三：执行筛选规则

### 目标
基于阶段二计算的指标，按三层规则逐只判断，输出通过筛选的精选池。

### 筛选逻辑总述

模型二寻找三类量价形态：
- A类：缩量回调至均线支撑（主力建仓后洗盘，缩量回踩MA20或MA60）
- B类：底部盘整后初次放量突破（刚突破MA60，涨幅还不大）
- C类：上升趋势中的健康回踩（多头排列，缩量回踩MA20不破）

不选的形态（一票否决）：
- 空头排列（MA20 < MA60）：下降趋势，不选
- 近5日涨幅 > 20%：已经加速拉升，不追
- 收盘价 < MA60 且 MA20 < MA60：深度回调，趋势已坏
- 近20日均量持续低迷且无量比放大：无人关注

### 筛选规则

**前置检查 — 排除不符合基本条件的标的**（以下任一满足即排除）：
1. MA20 < MA60（空头排列）
2. 近5日涨幅 > 20%（已加速拉升）
3. 收盘价距60日高点 < -30% 且 近20日涨幅 < -15%（深度回调且仍在持续下跌，不是已止跌企稳；若距60日高点 < -30% 但近20日已不再跌，说明可能已见底企稳，不排除）

**A类：缩量回调至均线支撑**
- A1-前期放量：近20日内有过至少1天量比 > 1.5（前期有资金进场迹象）
- A2-当前缩量：缩量程度 < 0.85，即近5日均量 < 近20日均量的85%（当前在缩量，主力没跑；0.85 捕捉缩量早期阶段，避免阈值过严漏掉刚开始回踩的标的）
- A3-均线支撑：距MA20在 -5% ~ +3% 之间，或 距MA60在 -5% ~ +3% 之间（回调到关键均线附近）
- A4-趋势未坏：MA20与MA60差距 > -3%，即不是空头排列（趋势仍然向上或盘整）

**B类：底部盘整后初次放量突破**
- B1-前期盘整：最近 10 个交易日中，至少有 7 天的 `\|MA20_MA60差\| < 5%`，即均线持续粘合（之前处于盘整状态，单日粘合不足以说明盘整）
- B2-放量突破：最近3个交易日内有过至少1天量比 > 1.5（最近有放量）
- B3-站上均线：收盘价 > MA60（突破长期均线）
- B4-涨幅不大：近5日涨幅 < 15%（还没加速，处于突破初期）
- B5-有量能基础：近20日均成交额 > 100万元（过滤日均成交额不足百万的僵尸股，成交额统一标准对高/低价股公平，避免 1万股门槛在 500 元股和 5 元股之间差 100 倍）

**C类：上升趋势中的健康回踩**
- C1-多头排列：MA20 > MA60（处于上升趋势）
- C2-缩量回踩：缩量程度 < 0.85（回踩时缩量）
- C3-回踩MA20：距MA20在 -5% ~ +3% 之间（回踩到中期均线）
- C4-未破前低：收盘价 > 20日最低价的105%（没有破位）
- C5-涨幅不大：近5日涨幅 < 15%（还没加速）

**筛选通过条件**：满足 A 或 B 或 C 任一类全部条件，即为通过。

**多类别重叠处理**：当一只股票同时满足多类条件时，按 C > A > B 的优先级归类（上升趋势中的健康回踩确定性最高，缩量回调次之，底部放量突破确定性最低）。每只股票只标记一个类别。终端摘要和 CSV 输出均按此优先级。

### 预期输出
通过筛选的股票列表（dict），每条包含：代码、名称、通过类别（A/B/C）、关键指标值。

## 附录：设计说明与优化预留

### 模型二定位再确认
- 模型二不产生交易信号，输出精选池供模型三做深度估值
- 筛选通过不代表"立即买入"，代表"值得进入下一阶段研究"
- 最终交易决策由模型四（择时跟踪）在估值到位+技术信号共振时触发

1. 缩量程度阈值 0.85（v1.2 已从 0.8 调整）：后续可根据流通市值分段进一步细化

3. 近5日涨幅上限 15%-20%：是否需要区分A类（回调型可放宽）和B类（突破型应更严）
4. 均线参数 MA20/60：是否需要增加 MA120 作为长期趋势参考
5. 北向资金：是否在后续版本中纳入妙想资讯Skill的北向资金流向数据，作为辅助验证
