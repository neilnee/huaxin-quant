# 模型三：深度估值模型（自执行指令）

- **版本**: v1.2（发布版）
- **日期**: 2026-05-20
- **核心目标**: 对模型二精选池中的每只标的，进行基本面穿透和估值建模，输出安全边际价格区间。同时挖掘未被市场充分定价的预期差，识别催化事件，为模型四提供交易决策的估值锚点和跨标的优先级排序。
- **核心哲学**: 用一手数据做判断，不用二手标签做决策。估值方法由决策树分派（脚本算信号，LLM 走流程），所有标的强制输出隐含PE作为统一参照系。从财务信号中定位预期差方向，不做撒网式搜索。跨标的用安全边际折扣率统一排名，不管底层用什么估值方法。不推翻历史分析，做增量迭代。
- **输入**: `quant/quant_<YYMMDD>.csv`（模型二产出）
- **输出**:
  - `reports/<股票代码>_<股票名称>.md`（每只标的独立研究报告）
  - `reports/_index.csv`（研究状态 + 阶段进度追踪）
  - `reports/_ranking.csv`（跨标的横向对比，供模型四优先级排序）
- **配套脚本**: `scripts/valuate.py`（v1.0-dev，负责数据拉取、缓存管理、财务指标计算、报告骨架生成；LLM 负责定性分析和叙事撰写）

---

## 总览

本任务分 **6 个阶段**，每阶段有明确的输入、输出和操作规范。

```
阶段零（数据准备/脚本）→ 阶段一（业务拆解+自算预测）→ 阶段二（一致预期与定价基准）
→ 阶段三（预期差挖掘与独立估值）→ 阶段四（催化剂识别）→ 阶段五（输出研究报告+横向排序）
```

**核心设计原则**:
- **脚本做计算，LLM 做判断**：财务数据拉取、缓存管理、指标计算、报告骨架由 `valuate.py` 固化；定性分析、搜索综合、叙事撰写由 LLM 完成
- **数据源分层，可信度标注**：核心财务用妙想金融数据，扩展分析用联网搜索，每条关键数据和结论标注来源
- **估值方法决策树分派 + PE 统一参照**：脚本计算五个客观信号（Q1 利润质量 / Q1b 高增长营收 / Q2 资产轻重 / Q3 利润稳定性 / Q_IRREG 重大非经常性），LLM 按决策树路径自动分派估值方法；无论分到哪种方法，所有标的强制输出隐含PE，用安全边际折扣率做跨标的统一排名
- **预期差从财务信号出发**：先看财务数据有没有线索（在建工程高→搜产能，研发费率高→搜技术），再定向深挖，不做 6 方向撒网
- **研究报告支持增量迭代**：新信息以时间线方式追加，历史分析归档到 `archive/`，主报告保持精简
- **阶段状态可追踪**：`_index.csv` 记录每个标的的各阶段完成状态，中断后可续跑
- **脚本版本与指令版本同步**，规则变更时两者同步更新
- **缓存复用**：同一报告期内的财务数据缓存复用（`cache/financial/`），避免重复 API 消耗

## 阶段零：数据准备（脚本执行）

### 目标
批量拉取标的的财务数据和研报摘要，计算标准化财务指标，写入缓存。产出结构化的"简报册"JSON，供 LLM 在阶段一~四中直接引用，不做数值搬运。

### 执行方式

```bash
python3 scripts/valuate.py                          # 默认：处理 _index.csv 中全部待处理标的
python3 scripts/valuate.py --test                   # 测试模式：只跑前 2 只
python3 scripts/valuate.py --code 300442            # 单只覆盖/更新
python3 scripts/valuate.py --phase 0                # 只跑阶段零（刷新数据缓存）
python3 scripts/valuate.py --no-cache               # 强制跳过缓存，重新拉取全部数据
python3 scripts/valuate.py --pool pool/pool_260518.csv --quant quant/quant_260518.csv  # 指定输入
```

### 脚本职责

**0.1 进度检查**
- 读取 `reports/_index.csv`（如不存在则从 `quant/quant_<YYMMDD>.csv` 初始化）
- 对每只标的判断：首次覆盖 / 持续跟踪 / 数据已拉取可跳过

**0.2 财务数据拉取与缓存**

通过妙想金融数据 Skill（mx-data）拉取每只标的以下数据。**必须指定 `--output-dir cache/financial/`**，否则文件写入错误路径：

```bash
cd /Users/neil/.claude/skills/mx-data && python3 ./mx_data.py --output-dir /Users/neil/ai/quant_lab/cache/financial "{查询内容}"
```

拉取数据写入 `cache/financial/<code>_<YYMMDD>.json`：

| 数据类别 | 具体字段 | 缓存策略 |
|---------|---------|---------|
| 营收构成 | 分产品/分地区/分客户的营收、成本、毛利率 | 同一报告期缓存有效 |
| 核心财务 | 营收、归母净利润、扣非净利润、经营现金流、ROE、资产负债率、固定资产、总资产、折旧、总股本 | 同一报告期缓存有效 |
| 盈利质量 | 应收账款、存货、商誉、有息负债、净资产 | 同一报告期缓存有效 |
| 利润率趋势 | 过去 3-5 年毛利率、净利率 | 同一报告期缓存有效 |
| 估值指标 | PE(TTM)、PB、总市值 | 每日刷新 |
| 在建工程 | 在建工程/总资产，用于预期差漏斗判断 | 同一报告期缓存有效 |
| 研发费用 | 研发费用率，用于预期差漏斗判断 | 同一报告期缓存有效 |
| 海外营收 | 海外营收占比及增速，用于预期差漏斗判断 | 同一报告期缓存有效 |
| 资本事件 | 可转债、增发、重大收购、股本变动（用于识别潜在的股本摊薄和资本运作） | 每周刷新 |

缓存 key 含报告期标识（如 `2025-12-31`），报告期不变则缓存有效。每只标的约 2-3 次 mx-data 调用（19 只 × 2.5 ≈ 48 次，占日配额 ~10%）。

**0.3 财务指标计算**

脚本自动计算以下标准化指标（固化在 Python 中，LLM 不手工算）：

| 指标 | 计算方式 | 用途 |
|------|---------|------|
| 经营现金流/净利润 | OCF ÷ NP（2025 年报） | 盈利质量 + **估值决策树 Q1** |
| 应收账款/营收 | AR ÷ Revenue | 回款能力 |
| 存货/营业成本 | Inventory ÷ COGS | 库存健康度 |
| 商誉/净资产 | Goodwill ÷ Equity | 并购风险 |
| 有息负债/总资产 | Interest-bearing Debt ÷ Total Assets | 杠杆水平 |
| 固定资产/总资产 | Fixed Assets ÷ Total Assets | **估值决策树 Q2（资产轻重）** |
| 近3年毛利率波动 | max(毛利率_2023,毛利率_2024,毛利率_2025) − min(毛利率_2023,毛利率_2024,毛利率_2025) | **估值决策树 Q3（利润稳定性）** |
| **非经常性损益占比** | **(归母净利润 − 扣非净利润) / 归母净利润** | **估值决策树 Q_IRREG + 预期差漏斗** |
| 在建工程/总资产 | CIP ÷ Total Assets | **预期差漏斗：产能扩张信号** |
| 研发费用率 | R&D ÷ Revenue | **预期差漏斗：技术突破信号** |
| 海外营收占比 | Overseas Rev ÷ Total Rev | **预期差漏斗：海外拓展信号** |
| 前五大客户集中度 | Top5 Customer Rev ÷ Total Rev | **预期差漏斗：客户突破信号** |

**0.3.1 估值决策树信号（脚本自动判定）**

基于上述指标，脚本自动输出三个布尔/分类值，供阶段一决策树使用：

| 信号 | 判断逻辑 | 输出值 |
|------|---------|--------|
| **Q1: 有稳定利润？** | `归母净利润 > 0` **且** `OCF/NP > 0.5` | `true` / `false` |
| **Q1b: 有高增长营收？** | `营收 > 0` **且** `营收同比增速 > 30%`（仅 Q1=false 时使用） | `true` / `false` |
| **Q2: 资产轻重？** | `固定资产/总资产 > 40%` → 重 / `< 20%` → 轻 / 其余 → 中 | `重` / `中` / `轻` |
| **Q3: 利润稳定？** | 近3年毛利率波动幅度（max−min）< 5pct → 稳定 / ≥ 5pct → 波动 | `稳定` / `波动` |
| **Q_IRREG: 有重大非经常性损益？** | `非经常性损益占比 > 30%` → 触发；占比 ≤ 30% → 不触发 | `true` / `false` |

> **Q1 阈值说明**：OCF/NP > 0.5 确保利润有现金支撑，PE 估值有意义。OCF/NP 在 0.5~0.8 之间仍走 Q1=true 分支（PE 做辅助参考）。
> **Q_IRREG 说明**：当非经常性损益占比 > 30% 时，说明公司利润结构中有重大非经常性项目。这可能来自资产处置、资产证券化、并购重组损益、大额政府补贴等多种情况，不能一概而论。脚本自动标记后，必须联网搜索确定具体来源，然后按路线 A1 的 A/B/C 分类框架处理。
> LLM 在阶段一再结合业务理解确认，但脚本已提供客观信号，减少主观判断空间。

**0.4 预期差漏斗信号**

基于计算结果，脚本自动标注每条标的的预期差搜索优先级：

| 财务信号 | 阈值 | 对应预期差方向 | 搜索优先级 |
|---------|------|--------------|----------|
| 在建工程/总资产 > 10% | > 10% | 产能扩张 | **高** |
| 研发费用率 > 15% 且 营收增速 < 20% | > 15% | 技术突破 | **高** |
| 海外营收占比 > 30% 且 海外增速 > 国内增速 | > 30% | 海外拓展 | **高** |
| 前五大客户集中度 > 50% | > 50% | 客户突破/集中度风险 | 中 |
| 在建工程/总资产 5-10% | 5-10% | 产能扩张 | 中 |
| 研发费用率 > 8% | > 8% | 技术突破 | 中 |
| **非经常性损益占比 > 30%** | **> 30%** | **重大非经常性/资本运作（资产处置、资产证券化、并购重组、大额补贴等）** | **高** |

**未触发任何信号的标的**：跳过对应方向的深度搜索，预期差阶段仅做例行搜索（公司公告 + 行业政策）。信号为"高"的方向重点深挖，信号为"中"的方向简要覆盖，无信号的方向直接跳过。

**0.5 研报摘要拉取与缓存**

通过妙想资讯搜索 Skill（mx-search）拉取近期券商研报摘要。**必须指定 `--output-dir cache/research/`**，否则文件写入错误路径：

```bash
cd /Users/neil/.claude/skills/mx-search && python3 ./mx_search.py --output-dir /Users/neil/ai/quant_lab/cache/research "{搜索内容}"
```

拉取数据写入 `cache/research/<code>_<YYMMDD>.json`：
- 提取：一致预期营收/净利润增速、目标价区间、估值倍数及依据
- 提取：可比公司列表及估值对标数据
- 若妙想资讯返回不足 3 篇，标记"需联网补充"

**0.6 简报册输出**

脚本最终输出 `cache/briefing/<code>_<YYMMDD>.json`，结构化包含：
- 业务结构数据（分产品/分地区营收表）
- 盈利质量指标（5 项计算值 + 健康度判定）
- 利润率趋势表（3-5 年，含波动幅度）
- 估值决策树五信号（Q1 稳定利润 / Q1b 高增长营收 / Q2 资产轻重 / Q3 利润稳定性 / Q_IRREG 重大非经常性）
- 一致预期汇总（如有）
- 预期差漏斗信号及搜索优先级
- 估值指标快照（PE、PB、市值）

LLM 在阶段一~四中直接引用此 JSON，**不手工拉数、不手工计算**。

### 脚本工程约束
- 缓存损坏自动删除并重新拉取
- mx-data 调用串行，间隔 0.8s+抖动（复用模型二的 RateLimiter）
- 单只数据拉取失败标记到 `_index.csv` 的 `阶段零状态` 列，不阻塞其他标的
- 脚本版本号与指令版本号同步
- **缓存时效检查**：`valuate.py` 自动检测 `cache/financial/` 中超过 90 天的财报缓存文件并警告，提示重新拉取
- **`--no-cache` 清除旧简报缓存**：`python3 scripts/valuate.py --no-cache` 删除非今日的 `cache/briefing/` 文件后重新生成，不会删除财务原始缓存

## 阶段一：财报基本面与业务拆解

### 目标
基于阶段零输出的简报册，识别公司的真实业务结构，拆解每条业务线的核心驱动因素，并自算 2026 年规模预测（作为阶段二一致预期的交叉验证）。此阶段不联网。

### 数据源
- `cache/briefing/<code>_<YYMMDD>.json`（阶段零产出）
- 妙想金融数据 Skill（仅在简报册数据不完整时补充调用，同样必须指定 `--output-dir cache/financial/`）

### 分析步骤

**1.1 业务结构识别**

从简报册的营收构成数据中，逐条识别公司的真实业务线：
- 用自然语言重新命名每条业务，基于业务实质描述，不照搬软件标签
- 标注每条业务的：营收金额、营收占比（%）、同比增速（%）、毛利率（%）
- 判断每条业务的类型：成熟核心业务 / 成长业务 / 孵化探索业务

**1.2 业务驱动因素拆解**

对每条占比超过 10% 的业务线，识别其核心驱动因素。示例：
- 数据中心业务 → 机柜规模、上架率、单机柜租金
- 光模块业务 → 出货量（万只）、产品结构（800G/1.6T 占比）、均价趋势
- 半导体设备 → 出货台数、单价、毛利率爬坡进度

**1.3 估值方法选择（决策树，LLM 走流程不做数值判断）**

阶段零脚本已输出五个决策信号（Q1/Q1b/Q2/Q3/Q_IRREG），LLM 按以下决策树走流程分派估值方法。**不需要主观判断业务模式属于哪一类**，脚本信号已经确定路线。

```
决策树根节点：Q1 — 有没有稳定利润？
│
├─ Q1 = true（净利润>0 且 OCF/NP>0.5）
│  │
│  └─ Q2 — 资产轻重？
│     │
│     ├─ Q2 = 重（固定资产/总资产 > 40%）
│     │  │
│     │  └─ Q_IRREG — 有无重大非经常性损益？
│     │     │
│     │     ├─ Q_IRREG = true（非经常性占比 > 30%）
│     │     │  → 估值方法: 【分部估值：核心业务用对应方法 + 非经常性项目单独估值】
│     │     │    适用: 有重大资产处置、资产证券化、大额补贴或并购重组损益的重资产公司
│     │     │    ⚠️ 必须联网搜索确定非经常性来源，判断其性质（一次性/可重复/有持续性的经常化项目）
│     │     │
│     │     └─ Q_IRREG = false（非经常性占比 ≤ 30%，正常重资产）
│     │        → 估值方法: 【EV/EBITDA 为主 + 隐含PE验证】
│     │          适用: 传统IDC、重工制造、基础设施
│     │
│     ├─ Q2 = 轻（固定资产/总资产 < 20%）
│     │  → 估值方法: 【PE 为主 + P/FCF 验证】
│     │    适用: 软件、CXO、消费品牌
│     │
│     └─ Q2 = 中（20% ≤ 固定资产/总资产 ≤ 40%）
│        │
│        └─ Q3 — 利润稳定还是波动大？
│           │
│           ├─ Q3 = 稳定（毛利率波动 < 5pct）
│           │  → 估值方法: 【PE + DCF 交叉验证】
│           │    适用: 检测、游戏、品牌消费
│           │
│           └─ Q3 = 波动（毛利率波动 ≥ 5pct）
│              → 估值方法: 【PB + 周期调整PE】
│                适用: 化工、建材、周期制造
│
└─ Q1 = false（亏损 或 OCF/NP ≤ 0.5）
   │
   └─ Q1b — 有没有高增长营收？
      │
      ├─ Q1b = true（营收 > 0 且 营收同比增速 > 30%）
      │  → 估值方法: 【PS + PEG 为主 + 市场空间倒推验证】
      │    适用: 半导体设计、创新药、SaaS
      │
      └─ Q1b = false（营收增速 ≤ 30% 或 负营收）
         → 估值方法: 【净资产重估（PB）为主】
           适用: 困境反转、资产清算价值
```

> **关键规则**：
> - 决策树由脚本信号驱动，LLM 只需按 Q1→Q2→Q3→Q_IRREG 路径走到底，不主观选类别
> - 若公司同时具备多条业务线且特征不同（如成熟现金流业务 + 孵化亏损业务），对每条业务线**分别走一遍决策树**，各自独立计算业务线的股权价值（用各自分派的估值方法），最后将各业务线股权价值**加总**得到公司整体估值。不要试图加权平均不同方法的估值倍数
> - 当 Q_IRREG=true 时，非经常性损益**不是噪音**。必须联网搜索确定具体来源和性质，按路线 A1 的 A/B/C 三类框架分类处理。**严禁在未搜索的情况下直接扣除或忽略非经常性损益**
> - 无论最终落在哪个方法，**所有标的都强制输出"隐含PE"**（见阶段二 2.4），为横向比较提供统一参照

**1.4 盈利质量检查**

简报册已计算 5 项盈利质量指标。LLM 逐项标注"健康/关注/警示"并给出 1-2 句说明。

**1.5 利润率趋势**

简报册已提供 3-5 年毛利率和净利率趋势。LLM 标注趋势方向（稳定上升 / 稳定 / 波动 / 下降），若近一年变化超 3 个百分点，标注可能原因。

**1.6 规模预测（阶段一自算，用于交叉验证）**

基于业务驱动因素，对每条核心业务线做 2026 年的规模预测：

| 业务线 | 核心驱动因素 | 2025 实际 | 2026 假设 | 2026E 营收 | 2026E 利润 |
|--------|------------|----------|----------|-----------|-----------|
| <业务A> | <驱动因素> | XX 亿 | <假设说明> | XX 亿 | XX 亿 |

- 驱动因素的假设必须有依据（公司指引、行业趋势、产能数据），不能拍脑袋
- **利润预测为强制步骤，不允许跳过**。若当期扣非净利润受一次性因素影响（产能爬坡期、非经常性项目等），必须基于业务驱动因素做正常化调整后再预测。不能简单把当期扣非直接当作 2026E
- **利润预测拆解要求**：若公司在建工程/总资产 > 10%（产能扩张 HIGH 信号），或有明确的业务扩张计划，必须**逐项目拆解**利润增量来源：

  ```
  示例（适用于各类扩张模式）：
  
  2025 扣非基准: XX 亿
  + 已有产能正常化（爬坡完成、上架率提升等）: +XX 亿 (依据: ...)
  + 在建项目A预计投产贡献: +XX 亿 (依据: 公告建设进度/设计产能/行业平均回报)
  + 在建项目B预计投产贡献: +XX 亿 (依据: ...)
  + 并购/收购标的贡献: +XX 亿 (依据: 公告盈利预测)
  - 新增折旧/财务费用: -XX 亿 (若有)
  ─────────────────────────────
  2026E 核心利润: XX 亿
  ```
  
  不能只写一个总增速了事——每个主要增量来源都要单独列出并给出依据。

- **利润率正常化调整**：若当期利润率与历史中枢有明显偏离（如 +/-5pct 以上），必须分析偏离原因，判断是否会在预测期内回归：

  ```
  历史利润率中枢: 过去3年扣非利润率均值 = XX% (范围: XX%-XX%)
  当期利润率: XX% (偏离中枢 ±XXpct)
  偏离原因: [产能爬坡折旧前置 / 一次性成本 / 产品结构变化 / 其他]
  是否可逆: [是,预计XX季度内回归 / 否,结构性变化]
  预测利润率: [取中枢值 / 取当期值 / 取两者之间] (依据: ...)
  ```

  常见场景：(a) 重资产扩张期 — 当期利润率被折旧前置压低，爬坡完成后回升至中枢；(b) 产品结构升级 — 高毛利产品占比提升，利润率趋势性上移；(c) 一次性成本 — 剔除后利润率正常。**每种场景下预测利润率的取值逻辑不同，必须在报告中明确说明。**

- 自算的 2026E 净利润汇总后，与阶段二的一致预期做对比——偏差超过 20% 本身就是预期差来源。同时关注一致预期的分歧度（见 2.2），高分歧度 + 自算偏某一端 = 重要的估值立场选择

## 阶段二：一致预期与定价基准

### 目标
基于券商研报的一致预期，结合阶段一的决策树分派结果，用对应估值方法计算各项业务的基准估值（作为阶段三情景化汇总中各支柱的"基准情景"输入）。此阶段使用妙想资讯搜索 + 联网补充。

### 数据源
- `cache/research/<code>_<YYMMDD>.json`（阶段零产出）
- 妙想资讯搜索 Skill（优先，拉取近期券商研报，同样必须指定 `--output-dir cache/research/`）
- 联网搜索（补充，获取更多机构观点和行业估值参考）

### 分析步骤

**2.1 一致预期提取**

对每条核心业务线，搜索相关券商研报，提取：
- 未来 1-2 年的一致预期营收和净利润增速
- 券商给出的目标价区间和估值倍数
- 一致预期背后的关键假设

如果简报册中研报数量不足 3 篇，启动联网搜索补充。搜索词示例：
- `"<公司名称>" 研报 盈利预测 2026`
- `"<行业关键词>" 估值 可比公司 PE`

**2.2 与自算预测交叉验证**

将一致预期与阶段一的自算 2026E 对比：

| 指标 | 自算 2026E | 一致预期 | 偏差 | 判断 |
|------|-----------|---------|------|------|
| 营收 | XX 亿 | XX 亿 | ±XX% | 一致 / 自算偏保守 / 自算偏乐观 |
| 净利润 | XX 亿 | XX 亿 | ±XX% | 一致 / 自算偏保守 / 自算偏乐观 |

偏差超过 20% 的方向，标记为**潜在预期差**，在阶段三中重点搜索验证。
- **一致预期分歧度检查**：若拉取到多家机构数据，检查最高与最低值的偏差幅度：
  ```
  分歧度 = (最高值 - 最低值) / 均值
  若分歧度 > 50%: ⚠️ 市场对该标的缺乏共识
  → 必须在阶段三搜索各机构预测差异的原因
  → 常见根因: 非经常性项目处理方式不同 / 扩张节奏判断分歧 / 新业务预期不同
  → 分歧本身就是信号——自算预测落在分歧区间的哪一端，决定了估值偏保守还是偏乐观
  ```

**2.3 可比公司估值对标**

为每条核心业务线找到可比的 A 股/海外上市公司，提取：
- 可比公司的当前估值倍数（PE / EV/EBITDA / PS / PB，根据阶段一选定的方法）
- 可比公司的营收增速和净利润增速
- 公司与可比公司在业务规模、增速、毛利率上的差异

**2.4 定价基准线计算（按决策树分派方法）**

根据阶段一的决策树结果，选用对应的估值公式。**无论使用哪种主估值方法，每个价格锚点都强制计算"隐含PE"（= 估值结果 / 2026E 净利润），作为跨标的统一参照系。**

**路线 A: EV/EBITDA 为主（Q1=true + Q2=重 + Q_IRREG=false）**：
```
企业价值(EV) = 2026E EBITDA × 可比公司平均 EV/EBITDA
股权价值 = EV - 净有息负债
保守估值 = 股权价值 × 折扣系数
隐含PE = 保守估值 / 2026E 净利润
```

**路线 A1: 分部估值（Q1=true + Q2=重 + Q_IRREG=true）**：
```
⚠️ 此路线下公司存在重大非经常性损益。必须先通过联网搜索确定来源和性质，
   将"核心运营业务"和"非经常性项目"分开估值，不得简单剔除。

第一步：搜索并分类非经常性项目
  搜索词(通用): "<公司名称> 非经常性损益 来源"
  搜索词(定向): 根据行业特征调整（如资产证券化、补贴政策、资产出售公告等）
  
  将搜索结果归入以下三类之一:
  ┌──────────────────────────────────────────────────────────────┐
  │ 类型A: 一次性事件                                           │
  │   特征: 历史无重复、未来无明确计划                           │
  │   示例: 单次资产出售、诉讼赔偿、一次性政府补贴               │
  │   处理: 直接加回净利润 × 折扣系数(0.5-0.8)，不给予经常性PE  │
  │   估值倍数: 不给倍数（直接加回），或给 5-8 倍(极保守)       │
  ├──────────────────────────────────────────────────────────────┤
  │ 类型B: 可重复但非年度规律                                   │
  │   特征: 有历史先例、有明确的未来计划或管道、但间隔>1年       │
  │   示例: 资产证券化循环(每1-2年一次)、周期性资产处置         │
  │   处理: 年均化利润 × 合理PE(通常8-15倍，低于核心业务)       │
  │   关键: 必须列出管道中的每个项目、预计时间和规模             │
  │   估算: 若存在历史同类交易，用历史交易的财务比率推算未来:    │
  │     转换率 = 历史交易的(利润/交易规模)                       │
  │     未来项目估算利润 = 未来项目规模 × 转换率 × 调整系数      │
  │     调整系数: 规模更大→0.9-1.1, 市场环境变化→0.7-1.0       │
  │     注意: 该比率高度依赖具体交易模式，不可跨行业套用,        │
  │           必须在联网搜索中获取本公司历史交易数据作为基准     │
  ├──────────────────────────────────────────────────────────────┤
  │ 类型C: 有持续性的经常化项目                                  │
  │   特征: 每年稳定贡献、已融入主营业务                         │
  │   示例: 年度政府补助(如新能源补贴)、稳定的投资收益           │
  │   处理: 可按核心业务PE的 0.6-0.8 倍给出估值                  │
  │   估值倍数: 10-20 倍 PE(低于核心，高于类型B)                 │
  └──────────────────────────────────────────────────────────────┘

第二步：核心运营业务估值
  用路线A对应的估值方法（EV/EBITDA）对核心运营业务估值：
  企业价值(EV) = 2026E EBITDA(扣非口径) × 可比公司平均 EV/EBITDA
  核心股权价值 = EV - 净有息负债

第三步：非经常性项目逐个估值
  对搜索到的每个非经常性项目：
  - 分类到A/B/C
  - 量化: 
    · 类型A: 金额 = 搜索到的公告/研报中的预计额 × 实现概率
    · 类型B: 列出管道项目清单，每项标注预计金额和时间，折现后加总
    · 类型C: 年均金额 × 估值倍数
  - 估值增量 = 量化金额 × 对应倍数

第四步：加总
  保守估值 = 核心股权价值 + 类型A估值 + 类型B估值(折现后) + 类型C估值
  隐含PE = 保守估值 / (2026E扣非净利润 + 年均化非经常性利润)

⚠️ 管道清单强制要求:
  类型B的项目必须列出完整的管道清单（项目名称/预计时间/预计规模/依据来源），
  不允许仅凭"存在周期性"就拍一个总数。每个管道的项目需要独立验证。
```

**路线 B: PE 为主 + P/FCF 验证（Q1=true + Q2=轻）**：
```
合理PE中枢 = 可比公司PE均值 × (公司增速/可比增速) 调整
保守估值 = 2026E 净利润 × 合理PE中枢 × 折扣系数
FCF验证: 经营现金流 - 维持性capex = FCF，FCF收益率 > 5%
隐含PE = 合理PE中枢 × 折扣系数
```

**路线 C: PE + DCF 交叉（Q1=true + Q2=中 + Q3=稳定）**：
```
合理PE中枢 = 可比公司PE均值 × (公司增速/可比增速) 调整
保守估值 = 2026E 净利润 × 合理PE中枢 × 折扣系数
DCF交叉验证: WACC 8-12%, 永续增长 2-3%
隐含PE = 合理PE中枢 × 折扣系数
```

**路线 D: PB + 周期调整PE（Q1=true + Q2=中 + Q3=波动）**：
```
合理PB中枢 = 可比公司PB均值 × (公司ROE/可比ROE) 调整
保守估值 = 净资产 × 合理PB中枢 × 折扣系数
周期调整: 用过去3年平均净利润替代当期净利润做PE参考
隐含PE = 保守估值 / 过去3年平均净利润
```

**路线 E: PS + PEG（Q1=false + Q1b=true）**：
```
合理PS中枢 = 可比公司PS均值 × (公司毛利率/可比毛利率) 调整
保守估值 = 2026E 营收 × 合理PS中枢 × 折扣系数
辅助验证: 市场空间 × 目标市占率 × 稳态PE 倒推
隐含PE = 保守估值 / 2026E 净利润（若亏损则标注"N/A"）
```

**路线 F: PB 净资产重估（Q1=false + Q1b=false）**：
```
合理PB中枢 = 可比公司PB均值 × 调整系数
保守估值 = 净资产 × 合理PB中枢 × 折扣系数
隐含PE = N/A（亏损企业无有效PE）
```

> **PE 倍数取值量化规则**（适用于路线 B/C/E 等以 PE/PEG 为主估值的路线）：
>
> PE 倍数不能拍脑袋，按以下三步确定：
>
> **第 1 步：确定可比 PE 区间**
> 从可比公司对标表提取可比公司的 PE 中枢和上下沿（2026E 动态 PE）。若无可比公司 2026E PE，用 TTM PE × (1 + 增速) 估算。
>
> **第 2 步：增速调整**
> ```
> 增速比 = 公司未来12个月净利润增速 / 可比公司增速均值
> 调整后 PE = 可比 PE 中枢 × 增速比
> ```
> **上限约束**：调整后 PE 不得超过 `净利润增速 × 1.0`（即 PEG ≤ 1.0），也不得低于可比 PE 下沿。
>
> **第 3 步：定性溢价/折价**
> 在调整后 PE 基础上叠加定性因子，每个因子 ±5-10%：
>
> | 溢价因子 | 折价因子 |
> |---------|---------|
> | 行业龙头（Top3）+ 增速远超同行（>2x 可比） | 跟随者地位、市场份额流失 |
> | 结构性成长（如 AIDC 渗透、国产替代）且有订单验证 | 周期性强、盈利波动大 |
> | 确定性溢价：在手订单覆盖 12 个月+营收 | 客户/订单集中度高（Top1 > 50%） |
>
> **最终基准 PE = clamp(调整后PE × (1 + 定性调整), 可比下沿, 增速×1.0)**
>
> **实操规则**：
> - 增速与可比持平（±20%）：取可比 PE 中枢，不调整
> - 增速显著高于可比（>2x）：取可比上沿，上浮 10-25%，PEG ≤ 1.0 为硬上限
> - 增速介于之间：线性插值
> - 定性因子叠加在上述结果上，每个因子 ±5-10%，总调整不超过 ±20%
>
> **此规则写死在 LLM 执行流程中，不是可选建议。**

> **折扣系数确定**：龙头（行业 Top3 + 毛利率高于同业均值）→ 1.0；中游（行业 Top10）→ 0.85；跟随者 → 0.7。不搞一刀切的 0.8-1.0。

**2.5 三层价格锚点**

基于以上计算，输出每个业务线的估值锚点（作为阶段三各支柱的"基准情景"输入），每个锚点强制附带"隐含PE"：

| 价格锚点 | 市值(亿元) | 对应股价(元) | 隐含PE(倍) | 计算方式 |
|---------|-----------|-------------|-----------|---------|
| **保守估值** | XX.XX | XX.XX | XX.X | 阶段二计算输出（折扣系数 < 1.0） |
| **基准估值** | XX.XX | XX.XX | XX.X | 折扣系数取 1.0 |

> **隐含PE = 该锚点市值 / 2026E 归母净利润**（路线 D 周期股改用"过去3年平均净利润"作为分母，避免周期顶部/底部的利润失真）。亏损企业写 "N/A"。
> 阶段三将基于这两个锚点，结合各支柱的情景化三档（保守/基准/乐观），汇总输出完整的四层估值区间。
> 通过隐含PE，即使用 EV/EBITDA 或 PS 做主估值的标的，也能跟市场常用 PE 语言对标。

### 预期输出
定价基准线分析（三层锚点），含估值方法选择依据、可比公司对标表、一致预期交叉验证结果。关键数据标注 `【来源: 妙想资讯搜索】` 或 `【来源: 联网搜索-XX证券研报】`。

## 阶段三：预期差挖掘与独立估值

### 目标
基于阶段零输出的预期差漏斗信号，**定向深挖**高信号方向，找出市场尚未充分定价的增量业务、技术突破、产能扩张等预期差。对每条预期差独立估值，叠加到定价基准线上形成完整估值区间（四层价格体系）。此阶段必须联网搜索。

### 数据源
- 简报册中的预期差漏斗信号及搜索优先级（阶段零产出）
- 联网搜索（必须，但**只搜高/中优先级方向**，不撒网）

### 分析步骤

**3.1 定向搜索（按漏斗信号）**

根据阶段零标注的搜索优先级，执行定向搜索：

| 优先级 | 搜索策略 |
|--------|---------|
| **高** | **强制深度搜索**：至少 3 个不同关键词，覆盖公司公告 + 行业新闻 + 产业链信息。此级别的搜索不可跳过——这是指令卡的硬性要求，不是可选建议 |
| **中** | 简要覆盖：1-2 个关键词，关注公司公告为主 |
| **无信号/低** | 跳过该方向；仅做一次例行搜索（`"<公司名称>" 公告 2026`）确认无重大遗漏 |

**搜索关键词示例**（按方向）：

| 方向 | 深度搜索词（高优先级） | 简要搜索词（中优先级） |

**3.2 预期差清单整理**

对搜索到的预期差线索，逐条整理：

- 预期差名称：用一句话概括
- 业务实质：这块业务具体做什么、赚什么钱
- 当前状态：研发中 / 试产 / 小批量 / 即将放量
- 潜在利润规模：如果兑现，一年能贡献多少营收和净利润（**必须给出量化的估算依据**）
- 当前市场定价状态：未定价 / 部分定价 / 过度定价（判断依据是什么）
- 实现概率：高（70%+）/ 中（40-70%）/ 低（<40%），**必须给出概率判断的具体理由**

**3.3 每条预期差的独立估值**

对每条预期差，独立计算其估值增量：

- 估值增量 = 潜在净利润 × 合理估值倍数 × 实现概率

估值倍数的确定依据（与阶段一的决策树分派路线一致）：

| 预期差类型 | 估值倍数 | 依据 |
|-----------|---------|------|
| 稳定现金流型（如 REITs 出表、经常性服务收入） | 8-12 倍 PE | 可预测的经常性收入 |
| 高增长型（如 AIDC 切换、芯片放量） | 20-30 倍 PE 或 1-2 倍 PEG | 高增速溢价 |
| 早期孵化型（如第二曲线刚起步、未盈利） | 1-3 倍 PS | 尚无利润，看收入规模 |
| 资产重估型（如在建转固、产能释放） | EV/EBITDA 或 PB | 资产价值驱动 |
| 一次性事件（如资产出售、补贴） | 直接加回净利润 | 非经常性，不给倍数 |

> 估值倍数选择必须写明依据，不能只给数字。

**3.4 情景化估值区间汇总**

**核心原则**：估值区间来源于**每个支柱内部的不确定性**，而非"加不加某个业务"。每个支柱（主营业务、增长业务、期权价值等）都有自己的保守/基准/乐观情景，按情景加总得到整体估值区间。

---

**第零步：确定每个支柱的确定性等级**

在设定三情景之前，先根据支柱的业务实质判断确定性等级。这直接决定后续"基准取多少"和"保守取多少"。

| 确定性 | 判断标准 | 典型示例 |
|--------|---------|---------|
| **高** | 核心主业，3年+已验证盈利模式，历史数据充分，无重大审批/政策依赖 | 成熟业务线（如 IDC 运营、电力设备制造）、稳定现金流业务 |
| **中** | 有历史先例但非年度规律，或依赖审批/市场条件、存在执行不确定性 | REITs 扩募、产能爬坡中的新产线、海外新市场拓展、非经常性但可重复的资本运作 |
| **低** | 远期规划、早期孵化、高度依赖未验证假设、尚无利润或市场验证 | 远期管道项目（3年+）、未量产的新产品、第二曲线雏形、概念性期权 |

> 判断时看两个维度：① 有无历史验证（做过没）；② 兑现周期（多久能验证）。两维度都强→高，一个强一个弱→中，都弱→低。
>
> **上调因子**：以下情况可在上述判定基础上**上调半级**（低→低偏中→中）：
> - 有行业头部客户/合作伙伴明确背书（如英伟达、字节跳动等产业链核心企业）
> - 已有送样/验证/试产等实质性推进里程碑
> - 管理团队有该领域的成功履历
>
> 上调半级的含义：基准兑现比例从原区间的下半区移至上半区（如低确定性 30-50% → 40-60%，中确定性 70-90% → 80-95%）。**最多上调半级，不可跨级**（如低不能直接跳到中）。

---

**第一步：按确定性等级设定三情景**

**规则 1：基准的"确定性折扣"**

"最可能发生的情形"不等于"完整兑现分析"。确定性越低的支柱，基准取值越要打折。完整兑现是**乐观情景**的事。

| 确定性 | 基准取值（相对完整分析） |
|--------|---------------------|
| **高** | ≈ 100%（完整兑现分析结果） |
| **中** | 完整分析的 **70-90%** |
| **低** | 完整分析的 **30-50%** |

**规则 2：保守情景的"合理悲观"刻度**

保守是有可能发生的不利情景，不是末日。每支柱参考以下刻度从基准向下调整：

| 确定性 | PE/估值倍数折扣 | 利润/规模折扣 | 概率折扣（vs 基准概率） |
|--------|---------------|------------|---------------------|
| **高** | 基准倍数 × 0.90 左右 | 基准利润 × 0.93 左右 | 不适用（确定性高不依赖概率） |
| **中** | 基准倍数 × 0.80 左右 | 基准规模 × 0.75 左右 | 基准概率 × 0.6 左右 |
| **低** | 基准倍数 × 0.80 左右 | 基准规模 × 0.70 左右 | 基准概率 × 0.5 左右 |

> 保守刻度不是死数字，是参考区间。实际取值需结合具体情景（如高确定性支柱遇上系统性风险时可能跌破参考刻度，需在报告中注明触发条件）。
> 保守情景下每个支柱**仍应保留正估值**——只有实现概率确实 < 15% 的项目才能在保守中给 0。

**规则 3：乐观情景 = 完整兑现**

| 确定性 | 乐观取值 |
|--------|---------|
| 任意 | 完整兑现阶段二/三的分析结果（参数取上沿、概率取乐观端） |

无论确定性高低，乐观情景都按"分析全部兑现"取值。确定性高低影响的不是乐观值，而是**基准和保守值**——确定性越低的支柱，基准和保守离乐观越远，区间越宽。

---

**第二步：按情景加总**

```
保守估值 = 支柱一(保守) + 支柱二(保守) + 支柱三(保守) + ...
基准估值 = 支柱一(基准) + 支柱二(基准) + 支柱三(基准) + ...
乐观估值 = 支柱一(乐观) + 支柱二(乐观) + 支柱三(乐观) + ...
```

---

**第三步：输出四层估值区间**

```
下行风险价 = 保守估值 × 0.8（所有支柱同时最差 × 额外安全垫）
            →  XX.XX 亿元（对应股价 XX.XX 元，隐含 PE XX.X 倍）

            →  XX.XX 亿元（对应股价 XX.XX 元，隐含 PE XX.X 倍）
基准估值   = Σ 各支柱基准情景（确定性打折后）
            →  XX.XX 亿元（对应股价 XX.XX 元，隐含 PE XX.X 倍）
乐观估值   = Σ 各支柱乐观情景（完整兑现）
            →  XX.XX 亿元（对应股价 XX.XX 元，隐含 PE XX.X 倍）
```

> **隐含PE = 该锚点市值 / 2026E 归母净利润**（路线 D 周期股改用"过去3年平均净利润"）。亏损企业对应的锚点写 "N/A"。

|------|-------------|-------------|-------------|--------------|------------|--------|
| 保守 | <假设说明>  | <假设说明>  | <假设说明>  | **XXX** | XX.XX | XX.X |

**3.5 当前股价定位**

```

相对位置判断:
  - 低于下行风险价 → 深度低估（需排查是否为价值陷阱）
  - 在下行风险价与保守估值之间 → 有安全边际
  - 在保守估值与基准估值之间 → 合理偏低

判断公司的预期差是否在当前市场的主叙事线上，输出两个维度：

- **在叙事中的位置**：上游算力 / 中游平台 / 下游应用 / 能源配套 / 设备材料

模型三完成后，汇总所有标的的关键可比指标。**按"安全边际折扣率"升序排列（折扣率越低越靠前），不管底层用什么估值方法，折扣率是统一的排名尺度。**

| 1 | 股票代码 | ="300442" | |
| 2 | 股票名称 | 润泽科技 | |
| 3 | 主估值方法 | EV/EBITDA | 决策树分派的估值路线 |
| 4 | 当前股价_元 | 72.30 | |
| 5 | 保守估值_元 | 58.00 | Σ 各支柱保守情景，阶段三输出 |
| 6 | 隐含PE_保守估值_倍 | 23.2 | 保守估值 / 2026E净利润 |

| 8 | 隐含PE_乐观估值_倍 | 38.0 | 乐观估值 / 2026E净利润 |
| 9 | **安全边际折扣率** | **0.76** | **当前股价/乐观估值，越低越安全。此列排序，统一排名** |
| 10 | 距下行风险价 | +15% | (当前股价-下行风险价)/下行风险价 |

| 14 | 叙事匹配度 | 核心标的 | 核心标的/间接受益/边缘关联 |
| 15 | 综合优先级 | A | A/B/C，按规则计算 |

> **统一排名机制**：`安全边际折扣率 = 当前股价 / 乐观估值`。EV/EBITDA 估出来的转换成了隐含PE，PS 估出来的也转换成了隐含PE——但折扣率不需要转换，它就是价格和价值的比值，天然跨方法可比。

**综合优先级计算规则**：

```
优先级评分 = 安全边际折扣率得分 + 催化密度得分 + 叙事匹配得分

安全边际折扣率得分（折扣率 = 当前股价 / 乐观估值，与 _ranking.csv 第9列同口径）:
  - 折扣率 < 0.7（股价不足乐观估值七成，安全边际厚）: 3 分
  - 折扣率 0.7-1.0（股价在乐观估值附近或略低）: 2 分
  - 折扣率 1.0-1.3（股价略超乐观估值，预期差已部分定价）: 1 分
  - 折扣率 > 1.3（股价远超乐观估值，预期差已被透支）: 0 分

催化密度得分:
  - 近期催化 ≥ 2: 2 分
  - 近期催化 = 1: 1 分
  - 近期催化 = 0: 0 分

叙事匹配得分:
  - 核心标的: 2 分
  - 间接受益: 1 分
  - 边缘关联/无明显关联: 0 分

综合优先级:
  - A (5-7分): 高优先，模型四重点跟踪
  - B (3-4分): 中优先，模型四常规跟踪
  - C (0-2分): 低优先，模型四按需关注
```
