# 模型三：深度估值模型（自执行指令）

- **版本**: v1.4-dev
- **日期**: 2026-05-21
- **核心逻辑**: 三层估值 — Layer 1 共识锚定（充分定价）+ Layer 2 分歧挖掘（部分定价）+ Layer 3 预期差（未定价）。脚本做计算，LLM 做判断。简报册数据直接引用。
- **输入**: `quant/quant_<YYMMDD>.csv` | **输出**: `reports/<code>_<name>.md` + `_index.csv` + `_ranking.csv`
- **配套**: `scripts/valuate.py` | 参考手册: `03-valuation-ref-dev.md`

---

## 总览

```
阶段零（脚本）→ 阶段一（业务拆解+自算）→ 阶段二（共识+分歧）→ 阶段三（预期差）→ 阶段四（催化剂）→ 阶段五（输出+检查）
```

## 阶段零：数据准备（脚本执行）

```bash
python3 scripts/valuate.py                    # 全部待处理标的
python3 scripts/valuate.py --code 300442      # 单只
python3 scripts/valuate.py --no-cache         # 强制刷新
```

脚本自动完成：财务数据拉取 → 指标计算 → 决策树五信号判定 → 漏斗信号 → 简报册输出 `cache/briefing/<code>_<YYMMDD>.json`。LLM 直接引用简报册数据，不手工拉数。

### 决策树五信号速查

| 信号 | 判断逻辑 |
|------|---------|
| Q1: 稳定利润 | 归母净利>0 且 OCF/NP>0.5 |
| Q1b: 高增长营收 | 营收>0 且 增速>30%（仅 Q1=false 时触发） |
| Q2: 资产轻重 | 固产/总资产 >40%→重, <20%→轻, 其余→中 |
| Q3: 利润稳定 | 近3年毛利率波动 <5pct→稳定, ≥5pct→波动 |
| Q_IRREG: 非经常性 | 非经常性占比 >30%→触发 |

### 漏斗信号速查

| 信号 | 高优先级阈值 | 中优先级阈值 |
|------|-----------|-----------|
| 产能扩张 | 在建/总资产 >10% | 5-10% |
| 技术突破 | 研发费率 >15% 且 营收增速<20% | 研发费率 >8% |
| 海外拓展 | 海外占比 >30% 且 海外增速>国内 | — |
| 非经常性 | 非经常性占比 >30% | — |

## 阶段一：业务拆解 + 自算预测（不联网）

**1.1 业务结构识别**（强制记录）：从简报册营收构成出发，列出所有业务线的收入/占比/增速/毛利率，判断是否需要拆分。**判断结论必须写入报告**——拆分的说明各自估值方法，合并的说明"方法相同+增速差<20%+毛利率差<15pct→合并"。

**1.2 驱动因素拆解**：每条占比>10%的业务线，识别核心驱动（如机柜规模×上架率、出货量×均价、产能×利用率）。

**1.3 决策树分派**：脚本已输出 Q1-Q_IRREG。LLM 按树走到叶子节点，确定路线 A~F。**多条业务线特征不同时必须分别走树，加总得整体估值。**

```
Q1=true:
  Q2=重 → [Q_IRREG?] → A1(分部) / A(EV/EBITDA)
  Q2=轻 → B(PE+P/FCF)
  Q2=中 → [Q3?] → C(PE+DCF) / D(PB+周期PE)
Q1=false:
  Q1b=true → E(PS+PEG)
  Q1b=false → F(PB重估)
```

> 路线详情（公式/非经常性ABC分类/管道清单要求）见参考手册。

**1.4 盈利质量**：简报册 5 项指标逐项标注健康/关注/警示。

**1.5 利润率趋势**：标注方向（上升/稳定/波动/下降），近一年变化>3pct 时说明原因。

**1.6 自算 2026E 预测**（强制，按业务线）：

```
2025 扣非基准:    XX 亿
+ 增量来源1:      +XX 亿 (依据: ...)
+ 增量来源2:      +XX 亿 (依据: ...)
- 减项:           -XX 亿 (依据: ...)
─────────────────
2026E 核心利润:   XX 亿
```

若利润率偏离历史中枢 ±5pct，必须做正常化分析（偏离原因/可逆性/预测取值）。增速>100% 禁止线性外推。

## 阶段二：共识锚定（Layer 1）+ 分歧挖掘（Layer 2）

**2.1 共识提取（Layer 1 — 强制，双年度）**

mx-search 强制拉取研报（每只至少一次，不能仅依赖简报册。简报册 consensus 仅 `quality=verified` 时参考）。

```bash
cd /Users/neil/.claude/skills/mx-search && python3 ./mx_search.py --output-dir /Users/neil/ai/quant_lab/cache/research "<公司名称> 研报 盈利预测 2026 2027"
```

提取 ≥3 家机构的结构化数据，**同时拉取 2026E 和 2027E**：

| 机构 | 报告日期 | 2026E营收 | 2026E净利 | 2027E营收 | 2027E净利 | 目标价 | PE | 评级 | 关键假设 |
|------|---------|----------|----------|---------|----------|--------|-----|------|---------|

汇总表分两年输出（均值/中位数/最高/最低/机构数）。**6个月以上旧研报剔除。**

**2.1b 业务线拆分（强制）**：多条业务线且估值方法不同、增速差>20%、或毛利率差>15pct 时，逐条提取共识并独立估值。

**2.2 分歧量化（Layer 2 — 强制）**

分歧度 = (最高-最低)/均值×100%。

| 分歧度 | 定价状态 | 行动 |
|--------|---------|------|
| <20% | 充分定价 | 共识=基准 |
| 20-50% | 大部分定价 | 分析来源 |
| >50% | 部分定价 | 强制根因分析 |

**估值逻辑分歧**（分歧度>30% 或机构对同一业务线给差>30%PE 时强制）：

```
乐观叙事 (XX证券, PE XXx): [逻辑]
悲观叙事 (XX证券, PE XXx): [逻辑]
→ 我的判断: [偏向+依据]
→ Layer 2 调整: [取共识上沿/下沿/均值]
```

**你的立场**：自算 vs 共识区间。偏乐观→取共识上沿（需证据），偏悲观→取下沿，一致→不调整。

**2.3 交叉验证**：自算 vs 共识对比表。偏差>20% → 需在阶段三中验证假设，无证据→回归共识。

**2.4 可比公司锚定**：≥2家可比公司，提取 PE/PB/PS + 增速 + 毛利率，对比差异。

**2.5 定价基准计算**：用**共识净利**（非自算）代入决策树分派的公式。PE 取值三步走：

```
第1步: 可比PE区间（中枢+上下沿）
第2步: 增速调整 PE = 可比中枢 × (公司增速/可比增速)
       上限: PEG ≤ [结构性1.5 / 周期性1.0 / 成熟0.7]，且 ≥ 可比下沿
第3步: 定性调整 ±5-10%/项（龙头/高毛利/OCF强→溢价, 跟随者/周期/OCF弱→折价），
       总调整 ≤ ±20%
最终PE = clamp(调整后, 可比下沿, PEG上限)
```

> 增长质量判断：超高增速来自一次性爆发还是结构升级？增长跑道多长？无法回答→按周期性处理(PEG≤1.0)。

折扣系数：龙头1.0 / 中游0.85 / 跟随者0.7。

**悲观情景参数规则**：增长质量决定不确定性在哪端——悲观情景只压不确定的那一端，另一端维持基准。

| 增长质量 | 不确定性位置 | 悲观利润 | 悲观PE |
|---------|------------|---------|--------|
| 结构性成长 | PE端（情绪波动>基本面波动） | 共识均值（不压） | 基准PE × 0.90 |
| 周期性成长 | 两端均有 | 共识下沿 | 基准PE × 0.85 |
| 成熟/衰退 | 利润端（基本面风险>估值波动） | max(扣非, 共识下沿) | 基准PE（不压） |

> 逻辑：AI/AIDC/GLP-1的订单和产能是实物，不会因为情绪降温就消失。但光伏/化工的需求和价格确实会恶化。不确定性在哪里，悲观就压哪里。不搞"所有参数一起最差"的末日情景。

**Type B 管道清单估值规则**：管道中的每个项目独立估值后加总。公式：`Σ(项目利润 × PE × 概率)`，每个项目用自己的规模、时间、概率参数。**禁止**在计算外附加未拆解的 blob 数字（如"已确认管道溢价 +XX亿"）。远期项目（>2年）按阶段三 3.0 过滤规则处理，不给估值或给期权折扣。

### 2.6 2027E 估值（简化，同数据源）

基于同一套研报数据，对 2027E 并行估值。**核心框架不变，参数按以下规则迁移：**

**利润**：直接取 2027E 共识均值。若无可直接外推（增速>100%禁止线性外推），自算替代。

**PE/PB**：PE 锚定可比公司，不随年份机械下调。增速放缓是基数效应，不是生意变差。只有当增长质量降档（如结构性→周期性）时才调 PE 和折扣。

| 参数 | 来源 | 变化 |
|------|------|------|
| 共识净利 | 2.1 已拉取的 2027E 列 | 直接取共识均值 |
| PE倍数 | 同一生意同一组可比，不下调 | 仅增长质量降档时才调，否则沿用2026E |
| 悲观PE折扣 | 沿用 2.5 规则，增长质量降档则调整 | 结构性(×0.90)→周期性(×0.85) |
| 分歧(Layer 2) | 不改逻辑，仅调概率 | 扩募验证后概率上调（如55%→70%） |
| 预期差(Layer 3) | 时间推进，折扣收窄或取消 | 2年期权×0.5→1年×1.0 |

**不需要重做的事情**：业务拆分、分歧根因分析、可比公司选择、催化剂日历（沿用 2026E 的）。

## 阶段三：预期差发现（Layer 3 — 未定价）

**预期差 ≠ 分歧。** 分析师在讨论的=Layer 2，分析师没覆盖的=Layer 3。

### 3.0 最低执行要求（强制 — 每只必须完成）

以下两项**每只标的必须执行**，不论漏斗信号强弱。即使结果为空，也要在报告中记录"已搜索，未发现显著预期差"。

**路径 B（时间差）— 强制**：`"<公司名>" 公告 2026`。搜研报最新日期之后的新公告。
**路径 D（管理层）— 强制**：`"<公司名>" 增持 回购 股权激励`。

路径 A（漏斗）和路径 C（产业链）仅在漏斗有高/中信号时强制执行。

> **批量执行检查**：每只标的在进入阶段五写报告前，必须确认 3.0 的两条强制搜索已完成。未完成的标的不能输出报告。

### 3.1 搜索执行

漏斗路径（A/C）有高/中信号时强制执行；时间差(B)和管理层(D)每只必做。搜索关键词参考：
- 路径 B: `"<公司名>" 公告 2026`、`"<公司名>" 订单 中标 签约`
- 路径 D: `"<公司名>" 增持 回购 股权激励`
- 路径 A/C（漏斗方向）: 产能`产能 扩产 在建`、技术`研发 产品 验证`、海外`海外 出海 工厂`、资本运作`定增 收购`
- 路径 C（产业链）: `"<下游客户>" 2026 计划 指引`

### 3.2 预期差清单

逐条记录：名称、业务实质、当前状态、量化利润潜力、市场定价状态（未/部分/过度）、实现概率（高70%+/中40-70%/低<40%），概率必须有具体理由。

### 3.3 独立估值

估值增量 = 潜在净利 × 合理倍数 × 实现概率。倍数取值见参考手册。

### 3.4 三层估值汇总（强制输出到报告）

**矩阵结构** — 每个支柱在三层中都可能有贡献，不是一对一的：

```
                   Layer 1(共识)   Layer 2(分歧)    Layer 3(预期差)    合计
支柱一 [业务名]      ✓/✗/数值       ✓/✗/数值         ✓/✗/数值
支柱二 [业务名]      ✓/✗/数值       ✓/✗/数值         ✓/✗/数值
支柱三 [业务名]      ✓/✗/数值       ✓/✗/数值         ✓/✗/数值
```

每格标注该支柱在该层是否有贡献。有贡献填数字，没有填 `—`。标注每格的定价状态（充分/部分/未定价）。

> **归属排他性**：每条估值项（共识利润、分歧调整、预期差）只能归属一个支柱。如果某项与多个支柱相关，选最主要的归属，其他支柱标注 `—（见支柱X）`。禁止同一数字出现在矩阵的多个位置。

**汇总表**（按层合并）：

| 层级 | 悲观 | 基准 | 乐观 | 说明 |
|------|------|------|------|------|
| Layer 1: 共识基线 | Σ各支柱 | Σ各支柱 | Σ各支柱 | 已充分定价的部分 |
| Layer 2: 分歧调整 | ±Σ各支柱 | ±Σ各支柱 | ±Σ各支柱 | 部分定价，我的立场 |
| Layer 3: 预期差增量 | +Σ各支柱 | +Σ各支柱 | +Σ各支柱 | 未定价 |
| **合计** | | | | |

## 阶段四：催化剂识别

每条预期差绑定 ≥1 个催化事件。仅记录近期+中期。输出最低格式：

| 时间 | 事件 | 关联支柱 | 重要度 | 可检查 |
|------|------|---------|--------|--------|

主叙事匹配：<维度> / <位置> / 核心·间接·边缘。

## 阶段五：输出报告 + 反向检查

### 5.0 写入前检查清单（强制 — 每只必过）

```
□ 1.1 业务线拆分判断完成
□ 1.6 利润测算完成（逐项目拆解，≥3行增量来源，每行有依据）
□ 2.1 共识提取完成（≥3家机构, 2026E+2027E）
□ 2.2 分歧分析完成（分歧度% + 估值逻辑分歧≥1段）
□ 2.3 交叉验证完成（自算 vs 共识, 偏差>20%→验证或回归共识）
□ 2.4 可比公司锚定完成（≥2家, 含PE/增速/毛利率对比表）
□ 2.5 PE三步走完成，悲观参数规则应用
□ 3.0 路径B搜索已执行 + 路径D搜索已执行
□ 3.2 预期差清单已整理（含过滤结果）
□ 3.4 支柱×Layer矩阵已输出（每个支柱在三层中的贡献，归属排他）
□ 4   催化剂日历已输出（≥2条近期+中期事件）
□ 5.2 反向检查已执行（含触发/未触发+结论）
```

以上 12 项全部打勾才能写入报告。每只过一遍，缺一项即报告不完整。
- 利润测算最低要求：≥3行增量来源，每行标注依据。增速>100%禁止线性外推。利润率偏离±5pct须正常化分析。
- 支柱×Layer矩阵：每个支柱逐格标注 Layer 1/2/3 是否有贡献（数字或—），标注定价状态。同一条目禁止出现两次（归属排他）。
- 分歧分析最低要求：分歧度<20%→写"机构共识强，无显著分歧"；分歧度20-50%→说明分歧来源；分歧度>50%→强制展开估值逻辑分歧

### 5.1 报告输出

报告模板见参考手册。核心要求：
- 先给答案（估值区间），再拆公式，再列依据
- **报告结构顺序**：估值总览（含双年对照）→ 支柱一（2026E+2027E）→ 支柱二 → 支柱三（Layer 3 预期差, 必须有内容, 即使结论为"无显著预期差"）→ 催化剂日历 → 风险提示 → 研究更新记录。2027E 估值放在所有支柱之后、催化剂之前
- 支柱一必须含：计算逻辑、核心假设表、利润测算、可比公司、敏感性。**计算逻辑末尾必须输出市值→股价转换**
- 支柱二/三含：业务实质、计算逻辑、假设依据、管道清单（Type B强制，逐项列出每项目的规模/概率/估值）
- 所有数据标注来源（可信度：妙想金融/公司公告>券商研报>行业新闻）

### 5.2 反向检查（强制 — 写入报告前执行）

触发条件：

| 条件 | 动作 |
|------|------|
| 折扣率>2.0 或 <0.3 | 强制逐项检查利润预测/PE倍数/增长分类/可比公司 |
| 折扣率>1.5 且龙头 | 重新审视增长质量分类，检查PEG档位 |
| 折扣率<0.4 | 检查利润是否线性外推了不可持续的高增速 |

检查清单：利润可线性外推？利润率极端？PEG档位正确？可比公司合理？极端假设导致极端结论？估值区间宽度>5x？

结论写入报告：`🔍 反向检查：折扣率 X.XX [触发/未触发]。检查结论：[...]`

### 5.3 进度管理

`_index.csv`：每标的一行，记录各阶段状态（done/failed/pending）和日期。每完成一个阶段立即写回。

`_ranking.csv`：按安全边际折扣率（当前股价/乐观估值）升序排列。综合优先级 = 折扣率得分(0-3) + 催化密度(0-2) + 叙事匹配(0-2)。
