# 策略买点回测

- **核心目标**：检验前一交易日已经发布的 Signal Plan 在下一交易日形成实际可执行买点后，未来 5/10/20 个交易日的价格表现。
- **边界**：不依赖真实买卖，不模拟仓位、止盈止损、滑点或账户收益；不把形态成熟日和 Plan 发布日当作收益起点；不统计未成立计划的触发率。
- **输入**：`signal_plan/signal_plan_<YYMMDD>.json`、`cache/quant_runs/quant_<YYMMDD>.json`、共享日线库，以及买点成立日的市场与申万二级板块状态。
- **输出**：`backtest/backtest_<YYMMDD>.json|md` 及 Dashboard 独立回测数据包。
- **主脚本**：`scripts/backtest.py`。
- **策略配置**：`strategies/backtest.json`。

## 一、开发期规则契约

模型二负责识别 VCP 结构和三类买点，并通过 `setup_plan_inputs` 透出已经计算的价格、量能和失效阈值；Signal Plan 只把这些阈值转换为下一交易日计划。开发或修改相关规则时，必须一次性核对 PULLBACK / BREAKOUT / RETEST、NEW / FOLLOW、常规 / A 类、风险阻断和突破后生命周期的一致性，并用单元测试固化。该核对不是每日工作流步骤，历史回测和日常运行不得每次重复生成一致性审计。

Plan 必须保存来源 Quant 日期、`structure_anchor`、模型二阶段、当日买点和突破后生命周期，以便下一交易日只匹配同一只股票、同一轮 VCP。结构轮次优先使用 `contraction_group` 第一段开始日期；没有该字段时使用收缩段或突破日兼容标识。

## 二、实际买点事件

Plan 发布日为 `D`，只检查下一个有效交易日 `D+1`。Plan 发布本身不是回测事件；只有 `D+1` 收盘后的价格和成交量满足普通触发区、且收盘价未落入失效区时，才形成实际买点事件。

事件分为：

- `NEW`：前一日为允许形成买点的突破前有效 VCP，下一日首次满足 Plan 对应买点的普通条件。Plan 阈值已经来自模型二 `setup_plan_inputs`，运行时不要求模型二在下一日重复输出同名 `setup_signal`；只要求结构轮次一致、VCP 继续有效且未进入失败或过期生命周期。
- `FOLLOW`：前一日已经确认同类型买点，下一日仍满足 Plan 延续条件。它是原买点的次日有效执行窗口，不要求模型二重复输出一个新的首次信号，但下一日必须仍为同一轮有效 VCP，且不得进入失败或过期生命周期。

买点类型固定为 `PULLBACK`、`BREAKOUT`、`RETEST`。同一股票、同一结构轮次、同一买点类型、同一 `NEW/FOLLOW` 只记录第一次实际成立；连续计划不得重复占用样本。`NEW` 与 `FOLLOW` 表示不同进入时点，分组统计时不得混淆。

没有在 `D+1` 成立的 Plan 不形成事件、不记为失败，也不统计触发率。周末、节假日或历史误跑文件不得产生事件。

## 三、常规与 A 类

实际等级互斥：

- `A`：Plan 本身允许 A 类，且 `D+1` 同时满足理想价格区和理想量能条件。
- `REGULAR`：满足普通价格与量能条件，但未完整满足 A 类条件。

突破类普通条件为收盘价位于触发上下限内、成交量不低于普通下限；A 类要求收盘价位于理想区且成交量不低于理想下限。回踩与回踩确认类普通条件为收盘价位于触发上下限内、成交量不高于普通上限；A 类要求收盘价位于理想区且成交量不高于理想上限。所有类型均要求收盘价高于失效价。

满足 A 类的事件只记录一次并标记 `A`，不得同时进入 `REGULAR` 样本。A 类与常规的合计构成全部实际买点。

## 四、收益与滚动窗口

买点成立日 `E=D+1` 的收盘价是唯一收益基准。收益必须采用持有期总回报口径，不能直接用未复权原始收盘价相除：

```text
5日收益  = close(E+5)  / close(E) - 1
10日收益 = close(E+10) / close(E) - 1
20日收益 = close(E+20) / close(E) - 1
```

上式中的期末价值需包含 `E` 之后、目标日及之前发生的公司行为：送股和转增按比例增加持股数，现金分红计入现金收益，配股同时增加股份并扣除配股成本。买点成立日已经完成的除权除息不重复计算。除权数据优先读取覆盖报告日的本地缓存，缺失或缓存日期早于报告日时通过通达信除权除息接口补取；补取失败必须终止当日报告，不得静默退回未复权收益。事件输出需保留期间公司行为明细和收益口径，便于审计。

若持有期跨越除权日，突破判断也使用换算到买点日每股口径的持有价值与冻结 Pivot 比较，不得把除权后的原始股价直接与除权前 Pivot 比较。

以报告日 `T` 为观察截止日：买点年龄不足 5 个交易日时暂不进入页面窗口；年龄为 5~20 日时进入当期报告；超过 20 日后不再进入当期明细，历史日报保留结果。未走完相应周期时留空。停牌时使用不晚于目标交易日的最近有效收盘价。

每个事件继续冻结来源 Plan 的结构枢轴，从买点成立日起最多观察 20 个交易日；首次收盘价达到 `pivot × 1.01` 时记录突破日期、T+N 和相对枢轴涨幅。该字段只是辅助结构证据，不改变收益起点。

## 五、环境和统计

市场和板块状态使用买点实际成立日的同日环境，缺失时标记“环境待确认”，不得回退其他日期。

页面和报告输出总体 5/10/20 日样本数、胜率和平均收益，并按以下维度分组：买点类型、进入方式、实际等级、Plan 发布时的形态成熟度、买点成立日市场状态和板块状态。胜率定义为对应周期收益大于 0 的样本占比。样本不足时只展示事实，不自动调参。

## 六、每日工作流

每日 Quant、Signal Plan 和 Market Regime 完成后自动运行：

```bash
python3 scripts/backtest.py --date <YYMMDD>
```

脚本读取已经发布的历史 Plan 和下一交易日事实，发布 `backtest_context_<YYMMDD>.js` 并登记日期索引。每日流程不执行开发期规则一致性审计。
