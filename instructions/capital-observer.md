# 资金观测业务层（Capital Observer）

- **核心目标**：只用资金行为识别申万二级行业的成交额流入，并用妙想板块主力资金、核心个股主力资金和个股融资资金交叉验证。
- **策略边界**：不使用价格涨跌、均线、RPS 或 VCP 结构参与资金状态计算，不改写市场状态、模型二评分或买点。
- **观察单位**：板块只使用申万二级行业；申万一级只可作为展示归属，不参与筛选或妙想查询。
- **主脚本**：`scripts/capital_observer.py`。
- **策略配置**：`strategies/capital-observer.json`。

## 第一层：成交额流入

第一层完全读取共享通达信行情库。成交额统一使用金额，不汇总不可比的成交量股数。

```text
行业日份额 = 行业当日成交额 / 全 A 当日成交额
近3日份额提升 = 近3日平均份额 / 此前10日平均份额 - 1
流入加速度 = 近2日平均份额 / 此前3日平均份额 - 1
扩散度 = 当日成交额不低于个股此前20日中位数1.2倍的成员数 / 有效成员数
```

申万二级行业分别计算份额提升、当日份额历史分位、流入加速度、放量股票占比和最近3日持续性。候选必须通过绝对门槛，再按同层横截面分位评分；不得为了凑数强制选满。最多输出8个候选。这里的“成交额流入”指全市场成交额份额向该行业集中，不等于买卖双方意义上的净流入。

板块当日成交额由单只股票贡献超过45%，且放量股票占比低于20%时标记为单股集中并降权。有效成员少于3只、行情覆盖率低于90%或全A成交额占比过低时不得入选。

## 第二层：板块主力资金确认

最多对8个成交额流入候选查询妙想板块主力资金。只有申万—财富通映射质量为 `high` 或 `usable` 时才允许查询；`weak` 或 `unavailable` 明确返回映射不足，不生成板块主力资金结论。

板块层只观察订单流，不计算或汇总两融。主力状态独立输出为流入增强、持续流入、流入减弱、资金平衡、流出减弱、持续流出、流出增强或数据不足，不与价格状态合成。近3日方向和最新日/短期动量发生冲突时，必须优先标记为减弱，不得继续显示增强。

## 第三层：核心个股验证

对全部入选候选行业执行个股验证，最多覆盖8个行业。每个行业取最新交易日成交额前5只正常交易股票，一批查询个股主力资金和融资资金；跨行业结果允许由数据层缓存复用。板块映射为 `weak/unavailable` 时只跳过板块主力资金查询，不影响股票代码级查询，该行业明确标记为映射降级验证。板块主力资金未呈现流入也不再跳过个股查询，以便对8个候选保持一致的横向观测口径。

个股分别输出：

- 成交活跃度：相对自身20日成交额中位数的放大、正常或收缩；
- 主力资金：流入、平衡、流出或数据不足；
- 融资资金：加杠杆、稳定、去杠杆、不适用或数据不足。

融资数据只用于个股，必须保留实际数据日期；缺失值不得写成零。后续 VCP/Bloom 候选可按需加入个股查询集合，但不属于本模块第一版的板块核心样本。

## 请求预算

业务层由脚本串行调度，不使用并发绕过额度。默认单次逻辑请求预算20次：优先用于可映射候选的板块主力资金确认，再对全部入选行业的核心个股补数。按8个候选、每批5只股票计算，正常交易日预计使用15至16次请求。达到预算后保存已有缓存并输出 `partial`，下次运行自动复用缓存继续补齐。

默认 `run` 只基于通达信与已有资金缓存生成结果；只有显式传入 `--fetch` 才允许新增妙想请求。

```bash
python3 scripts/capital_observer.py run --date 2026-08-07
python3 scripts/capital_observer.py run --date 2026-08-07 --dry-run
python3 scripts/capital_observer.py run --date 2026-08-07 --fetch --max-mx-requests 20
python3 scripts/capital_observer.py publish-dashboard
```

## 输出与展示

```text
capital/capital_observer_<YYMMDD>.json
capital/capital_observer_<YYMMDD>.md
dashboard/data/<YYYYMM>/capital_context_<YYMMDD>.js
```

统一面板中新增独立“资金观测”页，位于“市场环境”右侧。主表展示最多8个二级行业的成交额流入与板块主力资金状态；点击行业后展示最新交易日成交额前5只股票的成交活跃度、主力资金和融资资金状态。页面必须先展示状态判定阈值，再展示候选准入、评分和一般口径说明；所有标准由业务数据包中的实际策略配置生成，不得在前端另写一套可能失真的规则。状态阈值必须按板块层、个股层和数据质量层分组，层内再区分成交额、主力资金和融资资金，禁止全部混排在一张长表中。页面不得自行访问数据库、妙想或重新计算指标。
