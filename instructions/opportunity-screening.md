# 人工机会初筛

最近更新：2026-10-11。

本规范用于盘后从系统候选中选出次日最值得研究的6—8只目标，合格者不足时如实输出。它属于人工研究流程，不属于自动工作流；字段、比较口径及输出模板见[配对参考](opportunity-screening-ref.md)。

## 研究目标

专注“明显推进上平台 → 成果保留、缩量收缩 → 尾段守位并有需求回应”的VCP形态，优先寻找下一个交易日可能出现参与条件的蓄力先手、突破或回踩机会。

先核结构质量，再比较供给、支撑、赔率与次日触发可能。仍需较长修复、仅有回撤减速或远期平台潜力的对象留作条件观察；详细参与价、失效确认与交易计划留到逐只研究完善。

## 1. 固定日期与输入

- 确认Pool、Quant全量、Bloom、Signal Plan、Market Regime使用同一分析日；次日计划按分析日生成的版本读取，标明对应交易日。
- Quant、Bloom和Signal Plan以策略库同日记录为权威，兼容JSON用于读取，不用仅含入选标的的Quant CSV代替全量扫描。
- 先读取最近研究笔记及讨论持仓表，落实用户已确认暂缓及原计划，带入本地已有财务风险；待核不等于已通过。正持仓单独复盘，已有当日初筛时核对更新，不重复排序。
- 复用本地共享行情与同日系统产物，核对历史覆盖、价格复权及量能单位；仅针对明确缺口补查。历史分析只用当时已知信息。

## 2. 合并候选来源

先排除持仓、数据异常、结构失效及硬风险。Bloom为`RISK_BLOCKED / DATA_ISSUE / INVALID / EXIT`的对象记录原因，不进入有效研究候选。

按代码合并去重以下五个入口：

| 入口 | 纳入范围 |
|---|---|
| 结构分 | 当前有效突破前VCP，V10原始结构分≥65，全部纳入 |
| 当日买点 | 当日Quant实际买点全部 |
| 次日计划 | 同一分析日Signal Plan涉及的股票全部 |
| 成熟结构 | 当前有效突破前`VCP_MATURE / VCP_TIGHT`全部 |
| 相对强度 | 当日全部有效结构候选中，20日全市场RPS前10；同分看60日全市场RPS |

- 65分只约束结构分入口，不能排除其他入口中的低分对象。
- RS前10从完整有效结构候选中取，不限定为其他入口之外的对象，不另加量价门槛；重复者仍占名额，合并去重后不递补。合格候选不足10只时取全部。
- 上一轮研究名单不自动加入；历史对象须重新满足本轮入口条件。
- 已突破的旧阶段标签不当作当前成熟蓄力结构；实际买点与次日潜在计划不得混写。
- 记录各入口数量、合并总数、排除与缺失情况；不以Bloom截取名单或自选同步名单代替全量扫描。有效性字段与RS缺失处理见配对参考。

## 3. 识别形态，做三项快看

先扫描候选字段，再核对相关完整推进—回撤段及末端日线，确认成果保留、真实底部与需求回应；不能只看轮次摘要或最后几根K线。已有数据足够时直接分析。

- **供给**：巨量冲高回吐、反复上试失败等强供给是否仍未修复，近期供给是否已有消化迹象。
- **支撑**：平台或收缩低点是否实际守住并有需求回应，不能把持续下移的新低当作已确认支撑。
- **赔率**：近端整体供给前的空间相对有效结构风险是否值得研究，不跳过供给或虚设更高支撑以改善比值。

近期强供给后，相关一轮推进被明显回吐，尤其全部回吐甚至跌回起点以下，且尚无新的承接及供给消化证据，不列重点；形成新承接、保留新推进并显示供给减弱后再评估。低点或重心仍下移时，缩量、收盘回撤收浅或单日高收不足以证明蓄力向上。

结构分、RS和成熟标签提供候选背景，不抵消上述反证或直接决定顺序。不新增加权分或赔率硬门槛；结构质量与参与位置相近时，优先次日更可能出现参与条件者。

## 4. 输出每日重点名单

按次日研究优先级输出名单，每只给一条核心理由。

- 一句话说明结构优势及次日可验证的参与条件；最强反证须影响取舍，不能只记在备注。不得用“分数高”“缩量收窄”或笼统“止跌待确认”替代入选依据。
- 输出代码、名称、候选来源、核心理由即可，代码不加粗。Pool来源及财务待核状态在来源或备注中标明，待核问题按需补充。
- 合格者不足6只时如实说明，不凑数；不再另设3—4只子名单。
- 其余候选按需记为条件观察、暂缓或数据待核，无需逐只填写完整研究表。

## 5. 记录与后续研究

合并到`daily_research/YYYY-MM-DD.md`，记录数据日期、覆盖与排除情况、候选数量、重点名单及核心理由。历史研究用于复核原判断与后续验证，不自动加回名单；同日已有记录保留原推理，补充新增证据与修正原因。

逐只研究时再完善供给与支撑证据、参与价、失效确认方式、空间/风险比及触发条件，财务待核者再核公告、经营与估值。市场状态用于调整后续风险预算和确认要求，不单凭环境标签否决候选。

初筛仅表示研究优先级，不触发买入、仓位、成交、自动策略修改或自选同步。
