# 人工机会初筛

最近更新：2026-10-25。

本规范用于盘后从系统候选中选出最值得研究的6—8只目标，优先下一交易日可能出现参与窗口者，同时关注未来几个交易日有潜力的结构，合格者不足时如实输出。它属于人工研究流程，不属于自动工作流；字段、比较口径及输出模板见[配对参考](opportunity-screening-ref.md)。

本环节专注量价：研究结构、供需、参与位置，以及个股与大盘、板块走势的配合。基本面、估值、财报及其他事件由独立环节分析，不在选图时新增查询，也不要求先完成这些核验才能进入量价研究重点。上游既有资格与风险门禁、用户明确操作约束继续保留；已有非量价备注原样交接，不作为本环节新增的技术排序或结构否决依据。量价结论不代表完整投资判断或交易授权。

## 研究目标

专注“明显推进上平台 → 成果保留、缩量收缩 → 尾段守位并有需求回应”的VCP形态，优先寻找下一个交易日可能出现参与条件的蓄力先手、突破临界或已有明确结构依据的回踩机会。

先核结构质量，再比较供给、支撑、赔率与机会接近程度。下一交易日可能有窗口者优先；已有蓄力依据、未来几个交易日可能成熟者也纳入研究与跟踪，不因尚缺一天确认而排除。仍需较长修复、仅有回撤减速或远期平台潜力的对象留作条件观察；详细参与价、失效确认与交易计划留到逐只研究完善。

候选入口用于保证覆盖，不直接决定研究重点。已突破展开、当前只有后续跟踪价值且需要等待新回踩或平台的对象，列为突破后跟踪，不因当日涨幅、放量或突破信号优先占据次日重点。已有清晰回踩结构和合理价格窗口时再评；初筛说明可能的参与路径、尚待确认的条件及下一交易日检查项，不要求每只都在下一交易日出现买点，也不预设准确成熟日期。

## 1. 固定日期与输入

- 确认Pool、Quant全量、Bloom、Signal Plan、Market Regime使用同一分析日；次日计划按分析日生成的版本读取，标明对应交易日。
- Quant、Bloom和Signal Plan以策略库同日记录为权威，兼容JSON用于读取，不用仅含入选标的的Quant CSV代替全量扫描。
- 先读取最近研究笔记、`daily_research/current_research_followups.json`（如存在）及讨论持仓表，带入原计划、暂缓原因与量价待验证问题；已有非量价备注留给独立分析接续，不写成已通过或已解决。正持仓单独复盘，已有当日初筛时核对更新，不重复排序。
- 暂缓表示降低研究优先级、继续跟踪，不作永久排除。保留暂缓日期、原因及待验证问题；研究优先级可随新证据恢复，无需等用户先解除标签。用户另有明确不买、敞口或其他操作约束时继续遵守，提高研究优先级不等于解除交易约束。
- 复用本地共享行情与同日系统产物，核对历史覆盖、价格复权及量能单位；仅针对明确缺口补查。历史分析只用当时已知信息。

## 2. 合并候选来源

先排除持仓、数据异常、结构失效及硬风险。Bloom为`RISK_BLOCKED / DATA_ISSUE / INVALID / EXIT`的对象记录原因，不进入有效研究候选。

暂缓标签不参与上述硬排除。满足五入口的暂缓对象正常纳入和去重，RS排名不因暂缓降权；不满足入口者也保留低优先级补充复核，核对原暂缓原因是否变化，但不冒称其通过本日入口或递补RS名额。存在独立数据或硬风险问题时，按实际原因记录。

按代码合并去重以下五个入口：

| 入口 | 纳入范围 |
|---|---|
| 结构分 | 当前有效突破前VCP，V10原始结构分≥65，全部纳入 |
| 当日买点 | 当日Quant实际买点全部 |
| 次日计划 | 同一分析日Signal Plan涉及的股票全部 |
| 成熟结构 | 当前有效突破前`VCP_MATURE / VCP_TIGHT`全部 |
| 相对强度 | 当日Pool内有效结构候选中，5日与20日全市场RPS各取前10，再合并去重；同分口径见配对参考 |

- 65分只约束结构分入口，不能排除其他入口中的低分对象。
- RPS5与RPS20分别从完整有效结构候选中取前10，不限定为其他入口之外的对象，不另加量价门槛；同榜及跨榜重复仍占各自名额，合并去重后不递补。某榜合格候选不足10只时取全部，缺失只影响该榜，不新增65分要求或混合加权分。
- RS选股范围限定当日Pool内符合现行有效性条件的对象；RPS数值仍用全市场横截面作参照，不因增加RPS5直接引入池外候选。池外覆盖只作诊断，入池规则问题回到Pool层单独评估。
- 上一轮一般研究名单不自动占据新重点名额；已明确重点跟进或持续跟踪的对象必须跨日补充复核，即使本日未再命中五入口也不静默丢失。暂缓对象同样按上述低优先级复核维护，均与五入口来源分开记录。
- 已突破的旧阶段标签不当作当前成熟蓄力结构；实际买点与次日潜在计划不得混写。
- 记录各入口数量、合并总数、排除与缺失情况；不以Bloom截取名单或自选同步名单代替全量扫描。有效性字段与RS缺失处理见配对参考。

用户要求补看强势板块、旧关注或其他范围时，补充对象与五入口按代码去重，注明独立来源、选择依据及实际覆盖，不修改五入口定义。板块代表股抽样不得写成板块成分股全量扫描；系统未覆盖或资料不足记待核，不冒称已有有效VCP。暂缓补充复核沿前述规则执行，不用待核或暂缓标签代替具体缺口与原问题。

## 3. 识别形态，做三项快看

先扫描候选字段，再核对相关完整推进—回撤段及末端日线，确认成果保留、真实底部与需求回应；不能只看轮次摘要或最后几根K线。已有数据足够时直接分析。

- **供给**：巨量冲高回吐、反复上试失败等强供给是否仍未修复，近期供给是否已有消化迹象。
- **支撑**：平台或收缩低点是否实际守住并有需求回应，不能把持续下移的新低当作已确认支撑。
- **赔率**：近端整体供给前的空间相对有效结构风险是否值得研究，不跳过供给或虚设更高支撑以改善比值。

近期强供给后，相关一轮推进被明显回吐，尤其全部回吐甚至跌回起点以下，且尚无新的承接及供给消化证据，不列重点；形成新承接、保留新推进并显示供给减弱后再评估。低点或重心仍下移时，缩量、收盘回撤收浅或单日高收不足以证明蓄力向上。

单根上影、一次下探或尚无实际买点不单独否定整体结构，须放回完整推进与回撤中判断。平台上沿的待突破位置与更上方整体供给分别核对，不因临近上沿一律排除突破前机会，也不跳过尚未消化的供给虚设收益空间。

负面价量证据须说明处理方式：结构依据被推翻时降级或撤回该轮假设；供给接受、承接或需求尚待确认时保留条件跟踪；整体结构仍成立的局部扰动和环境偏弱，影响后续风险预算及确认要求，不直接判定结构失效。数据异常与既有硬风险仍按入口门禁处理，不把所有不利现象一律当成排除项。

个股必须结合大盘及相关板块的同周期走势研究：核对推进、回撤、守位与修复的配合，区分板块共同推进、板块回落中的个股承接，以及个股自身供给压力。板块强不替代个股结构，板块弱也不直接否定有效蓄力；短期涨幅落后可能是整理，须看是否保留成果。板块背景用于解释供需、比较相近机会及安排验证，不新增打分或板块强弱硬门槛。比较口径与缺口处理见配对参考。

结构分、RS和成熟标签提供候选背景，不抵消上述反证或直接决定顺序。不新增加权分或赔率硬门槛；结构质量与参与位置相近时，结合板块配合，优先更接近参与窗口者，下一交易日机会排在未来几个交易日潜力之前，原暂缓对象可适度后置。时间远近用于排序，不作候选入选或持续跟踪的硬门槛，也不以临近触发抵消结构质量不足。出现新的推进保留、承接或供给消化时，须核对其是否解决原量价暂缓理由，并据证据提高研究优先级；非量价原因交独立环节，不因仍带暂缓标签而拒绝列重点，也不因单日反弹就认定原问题全部解决。

## 4. 输出每日重点名单

按研究优先级输出名单，优先下一交易日窗口，兼顾未来几个交易日潜力，每只给一条核心理由，不固定两类名额。

- 一句话说明结构优势、机会窗口（下一交易日或未来几个交易日）及待确认条件，简记相关板块的配合或背离；对尚未成熟者列出下一交易日检查项，不写成次日已可参与。最强价量反证须影响取舍，并说明属于失效、待确认还是预算/节奏因素。不得用“分数高”“缩量收窄”或笼统“止跌待确认”替代入选依据。
- 输出代码、名称、候选来源、核心理由即可，代码不加粗。Pool来源及量价数据缺口按需标明；已有基本面或事件备注另作交接，不混入量价核心理由或新增排序条件。
- 合格者不足6只时如实说明，不凑数；不再另设3—4只子名单。
- 其余候选按需记为条件观察、暂缓或数据待核，无需逐只填写完整研究表。
- 区分下一交易日参与窗口、未来几个交易日潜力、条件观察和突破后跟踪；前两类均可按质量列入研究重点，未在次日成熟者继续跟踪。研究价值不等于次日参与位置合适，量价重点不写成已满足全部买入条件。
- 暂缓对象补充记录本轮是否复核、原原因是否变化，以及下一次提高优先级需验证的证据；没有变化时可简记，不另造固定扣分。

## 5. 记录与后续研究

合并到`daily_research/YYYY-MM-DD.md`，记录数据日期、覆盖与排除情况、候选数量、重点名单及核心理由。历史研究用于复核原判断与后续验证，不自动加回名单；同日已有记录保留原推理，补充新增证据与修正原因。

跟踪总表滚动维护，每次正式更新后保存带研究日期、修订序号、变更原因及原文来源的历史快照；保留更新前已有版本，不覆盖旧快照。`daily_research/research_history_index.md`按股票链接每日笔记、研究产物与已保存状态，便于追溯进入、升级、降级及移出过程。每日笔记仍是原始推理依据，索引只导航，不从关键词命中推断历史结论或首次发现日期；历史未完整迁移时说明覆盖范围。路径与记录口径见配对参考。

逐只量价研究时再完善供给与支撑证据、参与价、失效确认方式、空间/风险比及触发条件。基本面及事件交独立分析接续，不是完成本环节的前置任务。市场与板块状态用于调整后续风险预算和确认要求，不单凭环境标签否决候选。

每次盘后人工研究先复核上一轮明确跟进对象，记录继续、提高优先级、转条件/突破后跟踪或撤销本轮研究假设及其证据，再筛新增。重点的延续假设、下一交易日验证和研究失效依据须留痕；具体交易失效价及确认方式未完成逐只研究时明确待定，不用临时日低点补造。RPS排名下降、结构分低于65或未再次入选入口不单独构成失效。

结构失效、参与窗口已走远和数据缺口分别处理：结构或依据被推翻时撤销该轮假设；价格已明显不合适时移出次日重点但可继续跟踪；量价数据不足时暂停对应技术判断。独立环节的基本面/事件结论及用户操作约束另行接续，不据此改写技术结构，也不将研究状态直接当真实持仓卖出。有效突破后的回踩/新蓄力仍可研究，不能把突破前65分当作所有突破后机会的持续门槛。

跟踪记录是人工研究接续，不等于后台自动监控；系统Pool/Bloom生命周期与人工逐只复核分别核对。RPS5补查仅扩大池内人工候选覆盖，不自动提高研究优先级、授予买点或更改Pool/Quant规则。

初筛仅表示研究优先级，不触发买入、仓位、成交、自动策略修改或自选同步。
